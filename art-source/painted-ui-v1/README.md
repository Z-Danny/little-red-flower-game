# 金绿手绘游戏 UI 资源

2026-09-15。用户授权将既有手绘图标、顶部倒计时和居中弹窗接入游戏。

## 交付

运行时资源在 `public/ui/painted-v1/`。PNG 为无损副本，WebP 为保留 alpha 的压缩版本。

| 名称 | 尺寸 | 用途 |
| --- | --- | --- |
| hint | 180×192 | 提示按钮 |
| pause | 192×189 | 暂停按钮 |
| back | 192×135 | 返回按钮 |
| petal | 184×192 | 倒计时指针，花瓣尖端朝下 |
| modal | 960×875 | 居中关卡弹窗；绿色标题、米白简介、金色主按钮 |
| timer-full | 1600×89 | 100% 金色倒计时素材 |
| timer-empty | 1600×89 | 0% 深绿倒计时底槽 |

三个图标和花瓣来自用户指定的既有图片。弹窗由内置 `image_gen` 去掉原右箭头；正文、标题和按钮均保持空白，文字由组件按关卡显示。满条与空槽由内置 `image_gen` 分别编辑原部分填充的倒计时素材生成。所有实际提示词记录在 `prompts.json`；来源绝对路径、SHA-256、裁切框、尺寸和布局坐标记录在 `manifest.json`。

## 接入坐标

所有值均以最终图片左上角为原点、单位为百分比。

- 弹窗标题安全区：left 22、top 5、width 56、height 15。
- 弹窗简介安全区：left 12、top 28、width 76、height 27。
- 弹窗按钮区域：left 10.8、top 63.7、width 76.4、height 18.3。
- 倒计时槽：x 3.9 至 96.1，中心 y 55。花瓣尖端位于花瓣图片 x 50、y 96。
- 满条与空槽采用同一裁切框和输出尺寸。ImageGen 在两态边框上存在轻微形状差异（360px 屏宽约 1px）；固定使用空槽作为完整外框，金色满条上移自身高度的 4.5% 后，只在 x 3.9—96.1%、y 34—76% 的内槽区域动态裁切，避免逐段替换外框。该限制已告知接入代理。

## 验证

- 七张 WebP 全部具有 alpha，alpha 最小值 0、最大值 255；无背景色烘焙。
- 人工图像检查确认弹窗文字区域为空，金色按钮无箭头；进度条无文字和固定百分比标记。
- 图标保持原有金黄主体、棕金描边、深绿叶片；小红花花瓣保持朱红渐变。
- Sharp 仅用于透明外边裁切、等比例缩放、增加透明留边、PNG/WebP 格式压缩。创意与内容编辑均通过内置 ImageGen 完成。
- 此目录不验证浏览器行为；最终游戏 HTML 的功能和视口验证由主任务执行。
