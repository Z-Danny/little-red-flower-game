# 油锅起火处置 · Godot 原型

关卡 ID：`oil-fire`。在 Godot 4.6.2 打开 `godot-prototype/project.godot`，可用 F6 单独试玩 `scenes/oil_fire.tscn`。从地图进入时，每次创建新场景；本关只发出 `finished(won, elapsed_seconds)` 或 `exited`，存档、奖励和结算由主界面处理。

## 规则与场景

- 点灶台旋钮，拖锅盖到锅口。两项顺序不限，在动画结束时提交。两项都完成后，拖人物到右侧门外。
- 水杯或本关的小化纤抹布落入未盖严的锅会立即将危险置满并锁定操作，反馈 1.90 秒后失败。锅盖已盖严时，水和抹布回到原位，不增加危险。只有一项处置完成时仍可能超时。
- 50 秒为训练参数。两项处置完成后，危险计时停止，记录用时仍计到人物撤离；0.65 秒安全过场不计入用时。暂停不计时。
- 根节点的 `Timing` 资源可修改时长。默认旋钮 0.65 秒、锅盖 0.85 秒、撤离 1.00 秒、普通回位 0.45 秒、错误道具动画 0.90 秒。取值来自 `content/response/kitchen-experience.json`，安全过场来自 `content/journey-timing.json`。
- `scripts/oil_fire_rules.gd` 提供独立规则接口 `tap_knob()`、`drop(item, zone)`、`advance(seconds)`。场景树中的图层、接收区 `PanZone` / `ExitZone` 和目标姿势可单独检查、编辑。拖放以道具中心落点判断，拾取用当前图层的不透明像素。

现实提示：油锅起火时，先关火，再用锅盖盖住，切勿直接泼水。火势失控时应立即撤离并拨打 119；儿童不要尝试灭火。火灭后保持锅盖覆盖，等待充分冷却。

## 自动化坐标

固定逻辑画布为 576 × 1024。沿用 `content/presets/kitchen/skin.json` 的原始场景坐标，在 Godot 世界节点中统一转换为 `(0.8x, 0.8y − 88)`。下表均为逻辑画布坐标；Web 测试按画布实际显示矩形等比缩放，并加上居中留边和画布偏移。

| 操作 | 按下 | 释放 |
| --- | --- | --- |
| 点击旋钮 | `(201, 390)` | 同点 |
| 拖放锅盖 | `(152, 689)` | `(214, 326)` |
| 拖放水杯 | `(315, 664)` | `(214, 326)` |
| 拖放抹布 | `(350, 343)` | `(214, 326)` |
| 拖人物撤离 | `(460, 416)` | `(484, 368)` |
| 返回／暂停／提示 | `(55, 50)`／`(129, 50)`／`(518, 50)` | 同点 |

旋钮和锅盖操作后分别等待至少 0.70 秒、0.90 秒再操作下一项；撤离释放后约 1.65 秒出结算。项目使用 Godot 的触摸模拟鼠标。

## 来源与原型差异

- 13 张厨房图层按字节复制自 `public/levels/paperbook-kitchen-v1/`；温度计外壳来自 `public/levels/kitchen-hud-v1/thermometer-shell.png`。未新制图片。温度计用程序绘制红色液柱，跟随规则风险，火势受控后清空。
- WAV 均来自 `public/audio/response-v1/`：音乐底轨、燃烧底轨、旋钮、锅盖、水、抹布、火焰扩大、撤离。没有人物声或朗读。
- 原版多轨混音、音效关键帧、烟尘／热浪粒子、角色呼吸微动、键盘辅助操作和绘本过场未完整移植；保留可见的火势变化、人物状态切换、道具动画及声音反馈。手机真机和人工试听未测。

## 测试

从仓库根目录执行：

```powershell
$godot = '.\outputs\godot-tools\editor\Godot_v4.6.2-stable_win64_console.exe'
& $godot --headless --path godot-prototype --import
& $godot --headless --path godot-prototype --script res://scripts/oil_fire_test.gd
```

测试覆盖两种顺序、未受控时撤离失败、盖严后忽略错误道具、两种未盖严错误、50 秒超时、受控后继续、暂停和返回。GUI 用例向 576 × 1024 的 Godot 视口发送真实按下、移动和释放事件；测试夹具禁用播放，不代替试听。
