## 通用处置数据引擎维护

content/levels/<id>/level.json 保存规则，skins/<style>.json 保存美术/动画，content/catalog.json 选择皮肤与启用状态；使用 scripts/levels.mjs。response 模板仍可创建处置草稿，不等于自动产生可审校的新知识或美术。

```powershell
node scripts/levels.mjs create --id response-draft --kind response --title 处置草稿 --order 25
node scripts/levels.mjs validate
node scripts/levels.mjs sync
```

先确认编号未使用，不要照抄示例编号。复杂新机制先扩展引擎并测试；不要把厨房专用皮肤当通用schema使用。皮肤切换沿用 levels:skin / levels:select-skin；玩法、图层、输入和适配分别验收。
