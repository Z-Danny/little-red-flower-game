# 睡前的卧室：电火花与扣时反馈

- 关卡ID：bedroom-night-check-v2。原图、目标蒙版、世界坐标、目标数量不变。
- 皮肤effects.electricSparks配置局部位置、半径、间隔与首发时间；本关定位在破损充电线接头(264,940)，半径30设计像素。
- app/game/scene-hunt/electric.ts提供共享360ms平滑包络；渲染与声音使用同一活动时钟。开始前、结局不演出；暂停冻结画面并静音，后台静音。减少动态模式仅用微弱稳定局部光，不闪烁。
- 声音由现有Web Audio交互通道生成滤波噪声和短下降音，无网络、无朗读、无需外部音频。每个周期只发一次，不补播遗漏周期。换肤只改皮肤锚点。
- 普通误点已存在5秒扣时；本次修复非最终描圈期间误点被忽略的问题。有效目标不排队，不重复处理；最后目标已命中则保护完成动画。
- 每次扣时增加1600ms局部“−5 秒”浮字，原进度条和短文字提示保留。浮字使用同一相机，不新建侧栏或数字倒计时。
- 自动浏览器测试可用CHALLENGE_SPARKS=1、CHALLENGE_LEVELS=bedroom-night-check-v2运行scripts/test-challenge-hud-browser.mjs。浏览器需独立存档、静音、finally关闭；计数与电平检查不等于人耳试听。
