# H12《林缘的五处火源》：5处隐患完整提示词

版本：2.0-至少五处-强化演出；原稿：42。作者编号不等于存档ID。

## 1. 单屏情境与完整构图

开场单条字幕：**教学观察：五处火源。现实应立即远离报告。**

虚构禁火林缘的应急教学观察图：五类不当火源组合在同一连续场景，人物已经位于与火源、烟气隔开的安全入口外。不是事故实录，也不让玩家在真实火场逗留；开场明确现实发现火情应立即远离报告。

构图：同一林缘土路及空地：左上便携炭烤炉正在工作；右上小型木柴火堆；左中石台上的烧纸金属盆，纸张边缘已燃烧；右中地面上一盒正在燃放的地面喷花烟花；左前景放大的独立烟灰盘里有未熄烟头。各火源之间有不燃地面，纸盆与木柴堆不是同一火点。背景自然标牌“本区禁火”；人物位于下方更远的入口外，不被烟气包围。

人物：巡护员与家人在安全入口外，成人原画有担忧神态并护住孩子一侧；五处火源都在人物以外的远侧。上身后倾、肩部收紧和呼吸逐档增强；不捂口进入烟中，不表演中毒或儿童灭火。

环境：本关允许在已存在燃烧源的核定区域增强火焰起伏、灰黑烟和稀疏火星；详见performance。实体、ID蒙版不动，烟火不吞没目标判据，不把全林自动点燃；无火源的另几关不复用这套火烟。

### 禁火区炭烤炉

- 可见判据：炭烤炉格栅下有红炭芯，旁边“本区禁火”背景标牌可见。
- 最小知识结论：禁火林区内不得野炊烧烤。
- 现实处理者与时点：远离、提醒成人或巡护人员处理；不是教孩子给炭炉泼水。
- 命中与剪影范围：禁火区炭烤炉。
- 完整结局结果：炭炉已由管理人员处置，未工作且无余火；家人仍在入口外。
- 两方核对：[S31 大鹏新区应急管理局安全文化发展中心：森林防火安全常识](https://www.dpxq.gov.cn/xxgk/wgk/glgk/jgxxgk/aqsc/content/post_12605312.html)；[S32 景泰县人民政府：森林防火封山令政策问答](https://www.jingtai.gov.cn/zfxxgk/zc/zczxwdk/byssthjjjtfj/art/2024/art_a53ce86b539547a989f9350a593e6dcc.html)。

### 未熄烟头

- 可见判据：前景烟灰盘、烟头红芯及相邻枯叶关系清楚；不把烟盒当燃烧证据。
- 最小知识结论：林区吸烟、遗留火种可能引发森林火灾。
- 现实处理者与时点：提醒巡护人员、远离火源；不让儿童手捡。
- 命中与剪影范围：烟灰盘及盘内未熄烟头为组合目标，保证手机可点击。
- 完整结局结果：烟头由管理人员彻底处置且现场检查完成，盘内无红芯；不教以看不到烟判断余火全灭。
- 两方核对：[S31 大鹏新区应急管理局安全文化发展中心：森林防火安全常识](https://www.dpxq.gov.cn/xxgk/wgk/glgk/jgxxgk/aqsc/content/post_12605312.html)；[S32 景泰县人民政府：森林防火封山令政策问答](https://www.jingtai.gov.cn/zfxxgk/zc/zczxwdk/byssthjjjtfj/art/2024/art_a53ce86b539547a989f9350a593e6dcc.html)。

### 禁火区篝火

- 可见判据：小型木柴堆有清楚但不夸张的火焰；位置在禁火标牌覆盖的林缘场景内。
- 最小知识结论：禁火林区内不能随意生火取暖。
- 现实处理者与时点：远离并报告；出现蔓延火情按现场指引撤离并求助，不参加冒险扑救。
- 命中与剪影范围：禁火区篝火。
- 完整结局结果：由专业管理人员处理火源并检查，不留未处理余火；不展示扑火技巧。
- 两方核对：[S31 大鹏新区应急管理局安全文化发展中心：森林防火安全常识](https://www.dpxq.gov.cn/xxgk/wgk/glgk/jgxxgk/aqsc/content/post_12605312.html)；[S32 景泰县人民政府：森林防火封山令政策问答](https://www.jingtai.gov.cn/zfxxgk/zc/zczxwdk/byssthjjjtfj/art/2024/art_a53ce86b539547a989f9350a593e6dcc.html)。

### 林缘烧纸盆

- 可见判据：金属盆里是多张可辨纸片，部分边缘正在燃烧；与木柴火堆分开，不能只画一摞未使用纸。
- 最小知识结论：禁火林区内烧纸属于应避免的不当用火，可能引发森林火灾。
- 现实处理者与时点：人员远离并报告巡护或专业人员；儿童不靠近抢取纸盆。
- 命中与剪影范围：烧纸盆与盆内纸片为一组，动态火焰和烟不作额外命中区。
- 完整结局结果：烧纸已由管理人员处理并检查，无余火；不把纸简单盖住就称处置完成。
- 两方核对：[S31 大鹏新区应急管理局安全文化发展中心：森林防火安全常识](https://www.dpxq.gov.cn/xxgk/wgk/glgk/jgxxgk/aqsc/content/post_12605312.html)；[S44 应急管理部新闻宣传司：应急管理部春节安全提示信息](https://www.mem.gov.cn/fw/jsxx/202001/t20200121_343685.shtml)。

### 林缘燃放的烟花

- 可见判据：地面喷花烟花外包装与持续喷出的短火花在原画中都可见；不是普通礼盒或未使用道具。
- 最小知识结论：禁火林区内不得燃放烟花爆竹，飞散火星有引燃风险。
- 现实处理者与时点：远离并报告管理人员，不靠近捡拾或尝试重新点燃。
- 命中与剪影范围：喷花装置实体为一组；飞散火花不是额外目标。
- 完整结局结果：装置由专业管理人员处置并完成检查，已无燃放与残火；不让家人接近未确认安全的装置。
- 两方核对：[S31 大鹏新区应急管理局安全文化发展中心：森林防火安全常识](https://www.dpxq.gov.cn/xxgk/wgk/glgk/jgxxgk/aqsc/content/post_12605312.html)；[S44 应急管理部新闻宣传司：应急管理部春节安全提示信息](https://www.mem.gov.cn/fw/jsxx/202001/t20200121_343685.shtml)。

## 4. 误点、完成与未完成反馈

**误点：**0—120ms误点处出现琥珀色短叉与扩散圈；120—450ms淡出，原人物上身轻缩一次，160ms下降双木音，单条字幕“这里没有识别目标，隐患仍未找齐。”；不扣分、不改pressure、不锁下一次有效点击，反馈自身限频500ms。

**单项找到：**描圈800ms后提交found，剪影220ms缩放1→1.12→1并增加完成标记，90ms确认木音；人物一次轻点头，尚未找到的风险和危机表演继续。

**全部成功：**最后found为t0：800ms留观→1800ms整图淡化→2900ms完整结果；t0+5500ms结算3花，花朵逐枚180ms出场，结算页保留待用户操作，背景声音平滑解除。

**主动结束未完成：**通过已有暂停菜单主动结束且不足5/5：冻结当前画面，显示“本次观察未完成 X/5”，不发花、不刷榜；提供重试和返回。不是90秒死亡失败，不播放人伤亡。后台切换不触发此结果。

完整结果：完整同构处置结果图：五类火源由专业管理人员处理并检查，火焰、红芯、喷花均停止，烟气散去，人物仍在入口外且肩部放松；以完整图和字幕说明另一个时点的专业处置结果。不描绘儿童浇水、捡烟头或搬燃烧物。

结果单条字幕：**图示为管理人员处置并检查后的状态。**

删掉的歧义：不把所有城市烧烤点都判违法；本关明确虚构禁火林区情境。删除旧版“火焰必须静止、不能有烟”的弱演出要求，改为已存在火源的分档表现；仍禁止新增未列火源、人物进入火场、用烟色判断毒性、把90秒当火灾蔓延规律或安全等待时间。

## 5. 原创声音

音色方案：forest_edge；BPM 66→92；音列素材：D3, G3, A3。

原创滤波噪声形成清楚的火焰呼吸声，短包络稀疏噼啪，后段增加低频紧张音垫与木质节奏；不使用烟花爆炸巨响、人声或真实警报。结局：火焰声随完整处置图淡出，G4–A4–D5解除音列，保留室外轻风。

全部为Web Audio原创合成，禁止人声与TTS；母线、包络、暂停及退出行为按总契约。
