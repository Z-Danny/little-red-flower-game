# H09《风雨中的街口》：5处隐患完整提示词

版本：2.0-至少五处-强化演出；原稿：9、1、13、4。作者编号不等于存档ID。

## 1. 单屏情境与完整构图

开场单条字幕：**人在安全建筑内，找出街口五处危险。**

风雨教学观察图：人员已经在牢固建筑内的干燥高处，识别外部五处不能靠近的区域。镜头可观察不代表应在窗边看风雨；现实人员远离玻璃。

构图：从较高安全建筑向一个街口看，左上是积水地下通道；右上松动广告牌一角脱开；左中靠路边一口缺失井盖的检查井清楚露出井口；右中配电箱底部积水；左前景外部人行道侧的轻质围挡倾斜。下方保留室内人物区域。五处大小合理、互不重叠，不加开裂树枝作第六个隐藏目标。

人物：家人在建筑内部远离玻璃，成人上身略挡在孩子外侧，孩子紧靠成人；紧张呼吸与回缩逐档加重但不惊厥，不走出建筑。

环境：外景斜雨、风驱树叶和固定水域内涟漪逐档增强。积水区域边界、水位、广告牌和围挡实体位置保持固定；雨和叶片在人后。

### 积水的地下通道

- 可见判据：通道下行台阶与入口积水同时可见；自然“地下通道”标牌不是答案箭头。
- 最小知识结论：暴雨积水时不要进入地下低洼空间或贸然涉水。
- 现实处理者与时点：留在安全高处或沿确认安全路线绕行，服从现场指引。
- 命中与剪影范围：入口及实际下行积水范围；不圈整段道路。
- 完整结局结果：入口外由管理人员设置隔离，积水保留，家人仍在安全处。
- 两方核对：[S25 深圳市龙岗区应急管理局：暴雨过后，积水区风险提示](https://www.lg.gov.cn/lgajj/gkmlpt/content/11/11535/post_11535627.html)；[S26 北京市门头沟区人民政府：北京汛期安全避险指南](https://www.bjmtg.gov.cn/bjmtg/c102697/202606/d25c66526404437f8c551a357203f2f4.shtml)。

### 积水中的配电箱

- 可见判据：配电箱为明确电力设施，箱底围着积水，警示图形自然可见；不画人触摸。
- 最小知识结论：积水附近的电力设施存在触电风险，应远离。
- 现实处理者与时点：绕开并通知有关部门，不自行验证是否带电。
- 命中与剪影范围：箱体与其紧邻可见积水作为单一目标，不扩大到其他水面。
- 完整结局结果：设施周围被专业人员隔离，不能画孩子关电闸或抽水。
- 两方核对：[S24 深圳市气象局：暴雨天出行：注意积水远离电线](https://weather.sz.gov.cn/zhuanti/2014BaoYu/content/post_9695089.html)；[S25 深圳市龙岗区应急管理局：暴雨过后，积水区风险提示](https://www.lg.gov.cn/lgajj/gkmlpt/content/11/11535/post_11535627.html)。

### 缺失井盖的检查井

- 可见判据：井口的黑暗内部、金属边缘和移开的盖子可见，位置与另外两处水区分离。
- 最小知识结论：缺失井盖及积水遮掩的孔洞存在坠落风险。
- 现实处理者与时点：远离、提醒他人并报告，不能下井或用脚探测。
- 命中与剪影范围：井口及可见边缘；独立移开井盖不额外增加目标。
- 完整结局结果：管理人员设置隔离；井口仍不可通行，不由家人搬盖。
- 两方核对：[S24 深圳市气象局：暴雨天出行：注意积水远离电线](https://weather.sz.gov.cn/zhuanti/2014BaoYu/content/post_9695089.html)；[S25 深圳市龙岗区应急管理局：暴雨过后，积水区风险提示](https://www.lg.gov.cn/lgajj/gkmlpt/content/11/11535/post_11535627.html)。

### 连接脱开的广告牌

- 可见判据：招牌一角明确脱离支架、轻斜；不靠一小点锈斑判断。
- 最小知识结论：大风中应远离广告牌等有坠落危险的高处构件。
- 现实处理者与时点：人员远离，到牢固建筑避险，报告专业管理人员；不冒风加固。
- 命中与剪影范围：连接脱开的广告牌。
- 完整结局结果：广告牌下方被隔离，牌仍待专业处理。
- 两方核对：[S27 中央气象台：大风预警防御指南](https://www.nmc.cn/publish/country/warning/wind.html)；[S21 深圳市教育局：高空坠物避险指南](https://www.sz.gov.cn/hdjl/ywzsk/jyj/fwxx/xxaqgl/content/post_11148149.html)。

### 倾斜的轻质围挡

- 可见判据：工地围挡一块板及支脚倾斜，位置接近外部人行道，非稳定永久墙。
- 最小知识结论：大风中围板、棚架等临时搭建物需重点防范。
- 现实处理者与时点：人员绕开，交管理人员在安全条件下处置。
- 命中与剪影范围：倾斜的轻质围挡。
- 完整结局结果：围挡周围封控，危险板未被儿童扶正。
- 两方核对：[S27 中央气象台：大风预警防御指南](https://www.nmc.cn/publish/country/warning/wind.html)；[S01 应急管理部：台风来了，如何应对？](https://www.mem.gov.cn/kp/zrzh/202208/t20220809_419856.shtml)。

## 4. 误点、完成与未完成反馈

**误点：**0—120ms误点处出现琥珀色短叉与扩散圈；120—450ms淡出，原人物上身轻缩一次，160ms下降双木音，单条字幕“这里没有识别目标，隐患仍未找齐。”；不扣分、不改pressure、不锁下一次有效点击，反馈自身限频500ms。

**单项找到：**描圈800ms后提交found，剪影220ms缩放1→1.12→1并增加完成标记，90ms确认木音；人物一次轻点头，尚未找到的风险和危机表演继续。

**全部成功：**最后found为t0：800ms留观→1800ms整图淡化→2900ms完整结果；t0+5500ms结算3花，花朵逐枚180ms出场，结算页保留待用户操作，背景声音平滑解除。

**主动结束未完成：**通过已有暂停菜单主动结束且不足5/5：冻结当前画面，显示“本次观察未完成 X/5”，不发花、不刷榜；提供重试和返回。不是90秒死亡失败，不播放人伤亡。后台切换不触发此结果。

完整结果：完整避险结果图：五处危险区域由管理人员隔离，家人仍在安全建筑并明显放松。积水、松动招牌和不稳围挡可以保留，等待专业处理；不能因找齐而晴天、排干或修好。

结果单条字幕：**人员已避险。积水和危险区域仍须远离。**

删掉的歧义：不宣称看不见的水下必有井；不画凭手杖探水即安全、不按固定水深放行车辆。

## 5. 原创声音

音色方案：rain_street；BPM 66→88；音列素材：D3, A3, C4。

斜雨滤波噪声、低通阵风、加密木质低音；风雨占听感主导但不盖过点击回馈。结局：压低外部风雨而保留其存在，F4–A4–C5清楚解除音列。
