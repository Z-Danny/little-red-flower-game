# H08《日常家庭防震准备》：5处隐患完整提示词

版本：2.0-至少五处-强化演出；原稿：25。作者编号不等于存档ID。

## 1. 单屏情境与完整构图

开场单条字幕：**平时准备：找出五处防震布置隐患。**

普通晴天的家庭防震整理，没有地震预报、警报或正在震动的房屋。

构图：同一卧室兼书房：右上高柜固定带明显脱开；左上另一柜顶有沉重陶罐；床枕正上方有厚重镜框；左下房门通路被箱子挡住；右下独立坚固木书桌下堆满另一组箱筐，无法容身。桌下箱筐与门口箱子不连接，分别训练避震空间和通行路线。桌子远离玻璃、沉重悬挂物；五目标互不重叠。

人物：成人和孩子在中间空处，表情认真担忧；上身紧张动作可逐档变化，禁止被摇得站不稳、捂头躲震或惊恐乱跑，因为本图尚未发生地震。

环境：正常天气；没有地震、碎玻璃和低频地震轰鸣。以人物、边缘明暗及音乐推进表达准备的重要性，不伪造地震正在到来。

### 固定连接脱开的高柜

- 可见判据：镜头露出柜侧和墙面，防倾倒连接带一端已脱开；不凭看不见柜背断定没固定。
- 最小知识结论：高大家具需可靠固定，降低倾倒风险。
- 现实处理者与时点：由成人按产品和安装要求固定，必要时请专业人员；不在震动中处理。
- 命中与剪影范围：柜体及可见断开连接件。
- 完整结局结果：连接件实际连住柜体与墙体，柜体尺寸位置不改。
- 两方核对：[S22 宝鸡市地震局：怎样做好家庭防震准备？](https://www.baoji.gov.cn/bmpd/bjsdzj/ztzl/dzkp/202506/t20250623_1160539.html)；[S23 吉林省地震局：中小学生安全教育日地震科普题库](https://dzj.jl.gov.cn/bsfw/dzkp_205394/dzcs/202403/t20240315_8882944.html)。

### 高处的沉重陶罐

- 可见判据：一只体量明显的厚陶罐放在柜顶边缘，下面有可用低层收纳空间。
- 最小知识结论：重物宜放低，减少震时坠落伤害。
- 现实处理者与时点：成人在日常整理中移至稳妥低处。
- 命中与剪影范围：高处的沉重陶罐。
- 完整结局结果：陶罐放在低层稳固位置，不占地面通道。
- 两方核对：[S22 宝鸡市地震局：怎样做好家庭防震准备？](https://www.baoji.gov.cn/bmpd/bjsdzj/ztzl/dzkp/202506/t20250623_1160539.html)；[S23 吉林省地震局：中小学生安全教育日地震科普题库](https://dzj.jl.gov.cn/bsfw/dzkp_205394/dzcs/202403/t20240315_8882944.html)。

### 床上方的厚重镜框

- 可见判据：床枕位置与上方厚重镜框在同一垂线上，悬挂关系完整；不是轻纸画。
- 最小知识结论：床上方不宜悬挂重物；悬挂物应摘除或可靠固定。
- 现实处理者与时点：成人日常移除床上方重物，交合适人员重新布置。
- 命中与剪影范围：床上方的厚重镜框。
- 完整结局结果：重镜框从床上方移走，床上方留空；不挪床伪造避开。
- 两方核对：[S22 宝鸡市地震局：怎样做好家庭防震准备？](https://www.baoji.gov.cn/bmpd/bjsdzj/ztzl/dzkp/202506/t20250623_1160539.html)；[S23 吉林省地震局：中小学生安全教育日地震科普题库](https://dzj.jl.gov.cn/bsfw/dzkp_205394/dzcs/202403/t20240315_8882944.html)。

### 门口挡路箱

- 可见判据：收纳箱横挡房门至床的正常通路；不包含其他正常收纳。
- 最小知识结论：日常应保持室内、门口和走廊通道畅通。
- 现实处理者与时点：成人事前整理，不等地震时才找路。
- 命中与剪影范围：门口挡路箱。
- 完整结局结果：箱子移入合适储物处，房门能开关、路线清楚。
- 两方核对：[S22 宝鸡市地震局：怎样做好家庭防震准备？](https://www.baoji.gov.cn/bmpd/bjsdzj/ztzl/dzkp/202506/t20250623_1160539.html)；[S20 石家庄高新技术产业开发区管理委员会官网：楼道堆物与消防通道安全](https://www.shidz.gov.cn/columns/2f7d8d4d-df82-4c78-8084-46b42f856986/202602/03/bf95da29-9e17-47db-8983-82d3d95e414b.html)。

### 被塞满的坚固桌下

- 可见判据：坚固桌脚、桌板与桌下成堆箱筐可见；箱筐占满原本可容身的桌下空间，而不是普通抽屉。
- 最小知识结论：日常应保留预先选定的坚固桌下避震空间，不用杂物塞满。
- 现实处理者与时点：由成人在平时清理；震动时不是先花时间搬杂物。本图不保证任意桌子都适合掩护。
- 命中与剪影范围：只含塞满桌下的箱筐组合；桌面和桌外地面不是目标。
- 完整结局结果：原桌下箱筐移入收纳区，留下清楚净空；桌子仍稳固，周边无玻璃或落物风险。
- 两方核对：[S42 台北市政府消防局防灾科学教育馆：地震可能造成的危险环境](https://fsm.119.gov.taipei/w/fsm119/Earthquake_21103013094789532)；[S43 美国疾病控制与预防中心 CDC：Preparing for Earthquakes](https://www.cdc.gov/earthquakes/safety/index.html)。
- 支持范围：S42直接支持桌下平时净空；S43支持家庭事前识别较安全位置及坚固桌下掩护。家庭书桌布局是二者结合的设计推导，不能扩成所有桌下都绝对安全。

## 4. 误点、完成与未完成反馈

**误点：**0—120ms误点处出现琥珀色短叉与扩散圈；120—450ms淡出，原人物上身轻缩一次，160ms下降双木音，单条字幕“这里没有识别目标，隐患仍未找齐。”；不扣分、不改pressure、不锁下一次有效点击，反馈自身限频500ms。

**单项找到：**描圈800ms后提交found，剪影220ms缩放1→1.12→1并增加完成标记，90ms确认木音；人物一次轻点头，尚未找到的风险和危机表演继续。

**全部成功：**最后found为t0：800ms留观→1800ms整图淡化→2900ms完整结果；t0+5500ms结算3花，花朵逐枚180ms出场，结算页保留待用户操作，背景声音平滑解除。

**主动结束未完成：**通过已有暂停菜单主动结束且不足5/5：冻结当前画面，显示“本次观察未完成 X/5”，不发花、不刷榜；提供重试和返回。不是90秒死亡失败，不播放人伤亡。后台切换不触发此结果。

完整结果：同构完整整理图，五处各自改善：固定高柜、重物放低、移开床上方镜框、清通道、腾出坚固桌下空间。家具位置尺寸不变，家人放松；不宣称可以阻止地震。

结果单条字幕：**识别完成。这些准备应在平时做好。**

删掉的歧义：不设计生命三角、预测90秒后地震、靠开柜门识别未固定；不把画面效果当建筑抗震验收。

## 5. 原创声音

音色方案：preparedness；BPM 62→78；音列素材：G3, B3, D4。

稀疏合成木音和轻弦感音垫，无地震预警提示音。结局：G4–B4–D5长尾音。
