# H02 / H04 / H08 室内关知识审校

审校日期：2026-09-10。完整读过三张制作卡及采用的网页/PDF段落。本记录是 AI 内容交叉检查，不是消防、医疗或工程认证；母版、蒙版和结局图尚待实际看图验收。

15 个最小知识目标均可保留，完整逐项证据及支持边界见 [indoor.json](./indoor.json)。

## 生产前必须落实

- H02：破损组件接独立插线板，再由插线板供电线接墙；不得把白供电线与黑组件线混成共用段。取暖器独立墙插。手机、折叠电热毯不能重叠为一个目标。鼓胀电池结局仍鼓胀、断开并待专业处理，不能把隔离画成修好了。
- H04：钢瓶、阀门、炉灶都在停用检查情境；无喷气、点火声或烟。软管和瓶上阀件的蒙版必须分清归属。结局是专业维护与成人整理后的另一时点，不能仅扶正瓶子就表示可以开火；电热水壶仍停用待处理。
- H08：高柜连接带脱开必须真正可见。重陶罐放在另一柜，不与未固定高柜重复计目标。被箱筐塞满的桌子必须坚固、远离玻璃和重悬挂物；箱筐与门口那一组独立。不能表现地震已发生、90 秒后将发生或保证任何桌下绝对安全。

- 应急管理部 S03 链接两次无法打开，未标作已读。损坏电线采用已读 [CPSC 海报](https://www.cpsc.gov/s3fs-public/elecsafety.pdf)与[沈阳消防访谈](https://www.shenyang.gov.cn/zwgk/zwdt/bxgz/202511/t20251121_4941005.html)补核。
- 卧瓶 S38 与 S39 的机理段高度同文，不算两份独立证据；加入[苏州公安提醒](https://www.suzhou.gov.cn/szsrmzf/mszx/202602/c3369e05be08407ca678175a75a94e0f.shtml)的直立放置与专业维修段。
- 宝鸡 S22 有不在本关采用范围内的“三角空间”表述，已明确剔除。H08 只采家具固定、重物放低、床上重物、桌下净空和通路整理，并用 [CDC 家庭地震准备](https://www.cdc.gov/earthquakes/safety/index.html)异源复核。
- [台北消防教育馆](https://fsm.119.gov.taipei/w/fsm119/Earthquake_21103013094789532)桌下净空段原情境是办公室。用于家庭坚固书桌是结合 CDC 家庭安全位置条件的设计推导，不能称原文直接规定了本图家具尺寸和布局。
