# 台风关：50秒限时挑战与声音设置（现行）

版本：2026-09-13（去尖叫修订）。台风声音与截止边界说明；所有12关共用HUD/限时合同见 `docs/challenge-hud/README.md`。本次不改原画、蒙版、命中坐标及统一视口。旧“超时继续找”“合成呼气”和“只有台风50秒”的说明均已退役。最新要求为保留背景音乐，只移除人物尖叫；不新增未经生成和试听的呼吸素材。

## 玩家流程与判定

1. 点击进入场景后开始50秒；暂停、隐藏网页不消耗时间。灯泡默认收起剪影，鼠标悬停/点击、手机点击展开，不显示具体秒数，仅保留横向铺满HUD的递减彩条。
2. 绿色（前25秒）→琥珀色（25–40秒）→红色（40–50秒）；风雨、节奏、人物动作共用活动时间，手机仍由共享视口等比cover铺满。
3. 50秒内点中全部目标：完成描圈后进入原有安全图和小红花结算。
4. 时间到仍未找齐：`failed`，计时固定在50秒，禁止晚到的场景点击，不展示安全图、不发奖励、不调用成功回调。
5. 失败文案：“时间到了，再挑战一次吧”；正文显示尚未找到的数量。`重新挑战` 一次点击清空本局红圈、提示和声音队列，重新从50秒开始。保留以前的最高成绩，不删除已有小红花。

### 边界必须一致

- 最后一次有效点击必须早于50.000秒。49.999秒点中最后目标后，强制800ms描圈可以播完；不能用强制动画耗时惩罚玩家。
- 50.000秒及之后再点击无效。尚未触发下一次tick时也有输入防线。
- 超时前已点击的非最后目标，即使描圈还未结束，也计入失败窗口“已找到”数量；这不构成通关。
- 失败/成功状态的后续tick及重复输入不能重复发奖。暂停与切后台不会在恢复时补扣时间。

## 模块职责与可替换点

|层|配置/代码|职责|
|---|---|---|
|玩法|`content/scenes/typhoon-home/rules.json`|`seconds:50`、`timeout:"fail"`；现有9个整场景观察关均显式启用fail；未配置timeout只保留历史兼容，不是生产默认|
|玩法引擎|`app/game/scene-hunt/model.ts`|计时、识别、deadline、failed及reset；不依赖图片/关卡ID/声音|
|文案与表现|`presentation.json`、`player.tsx`、`countdown-bar.tsx`|彩条、灯泡、失败窗口、可配置文案；不新建相机|
|声音时间表|`app/game/scene-hunt/tension.ts`|保留共用能力；台风关不再启用8/27/43秒人物惊叫|
|声音样本|`nonverbal.ts`、`fear-clips.generated.ts`|保留历史嵌入PCM及采样率转换；本关配置关闭，不创建这些样本的播放源|
|混音生命周期|`sound.ts`|背景音乐、环境、交互通道维持原逻辑；失败短终止音后静音；暂停/后台/退出停止|
|美术/适配|现有skin、renderer、共享viewport|完全保留现行空间关系和手机适配，不改变命中坐标|

台风关现为 `characterAudio:"none"`，关闭整组人物惊叫，暂停菜单不展示无效的“人物反应”开关。背景音乐仍默认开启并可单独关闭，风雨与交互音效保持原样；不以总静音代替去尖叫。尚未生成新的呼吸音。本次未删除旧样本，以保留出处和可追溯记录；[SOUND-LICENSE.md](SOUND-LICENSE.md) 仅说明历史素材，不代表现行台风关正在播放。禁止从历史脚本或报告恢复 `nonverbal-fear`。

## 复现与验收

在完整维护源码根运行：

```powershell
node scripts/verify-typhoon-50s.mjs
node node_modules/vinext/dist/cli.js build
node scripts/export-offline.mjs
node scripts/test-typhoon-50s-browser.mjs
```

验收输出在本目录 `verification`。测试覆盖0–4个目标超时、最后一毫秒点击、失败后迟点无效、一次点击重试、及时完成、其他8个找隐患关统一截止行为、原生浏览器50秒计时/音频生命周期及多尺寸布局。

浏览器测试隔离存档，硬件静音，finally关闭；不会修改玩家存档。现行测试在完整50秒内要求人物触发数为0、没有启动尖叫样本播放源、音乐开关仍开启；同时验证环境输出、暂停/后台/静音。浏览器RMS不能替代主观听感；真机与人耳试听未执行时明确记作not_run。旧verification是历史交付证据，本次去尖叫证据独立保存在 `docs/typhoon-no-scream/verification`，不重写过去已发生的验收结果。
