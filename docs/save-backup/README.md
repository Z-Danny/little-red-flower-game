# 本地存档体验与备份（2026-10-07）

## 范围
- 不接入账号/云服务，不增加外网请求，不改变各关规则、奖励或已有存档key。
- 保留已有“继续游戏”主按钮逻辑，增加首页存档管理入口；地图设置提供同一入口。
- 结算状态使用 provider 实际的 saved/session 标记，存储失败不会伪装保存成功。
- 备份只导出当前玩家资料、成绩（含合法但当前未启用的关卡ID）与全部解锁标记。不导出用户标识、不保存关中操作/地图位置/音量；多玩家分别操作。
- JSON严格校验格式、版本、大小、昵称、解锁类型、1～3整数分数及关卡ID。未知合法ID保留；危险对象键拒绝。
- 确认后总是创建新本机玩家并切换；不覆盖任何现有玩家、更高分数或其他玩家数据。与本机50玩家限制一致。
- 选择/预览/取消不写存档。确认时重新校验文件并校验当前玩家身份，避免其他标签页切换玩家后的误操作。
- 无法保存的会话仍可下载内存进度备份，UI明确警告。发起下载不等于用户已保存文件，因此提示要求确认下载位置。
