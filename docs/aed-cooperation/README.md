## 固定题设与知识边界

成人模拟患者仰卧在硬质地面的薄训练垫上。题设已经确认无反应、无正常呼吸；120 已呼叫，协助者正在 CPR，玩家刚取来 AED。

本题采用**预连接成人电极片的半自动 AED**。胸部贴片区域有汗水，因此先露出胸部、擦干贴片区域。未设置大量胸毛、植入装置、药贴、儿童或浸水环境等额外情况，不把这些情况简化成“一律擦一下即可”。不要求所有 AED 都有相同开机键、插头或电击键；真实操作须按具体设备及急救调度提示。

分析 / 设备就绪等待是压缩后的教学演示，不表示真实 AED 的标准耗时。训练不设生存倒计时、不用“花掉多少秒”判断医学结果。

**医学审校：not_run。游戏不替代正规培训。**

## 操作与反馈

| 阶段 | 玩家行为 | 人物与设备反馈 | 门禁 |
| --- | --- | --- | --- |
| 设备放置 | 将 AED 从地面工具区拖到患者身旁的干燥区域 | 设备实际移动落位 | 未放稳不能开机 |
| 开机 | 点击设备绿色电源键 | 屏幕亮起，显示当前短提示 | 开机不等于电击 |
| 准备胸部 | 点击上衣，再将干毛巾拖到胸部 | 衣物图层消失、水迹消退、毛巾回到工具区 | 未露出 / 未擦干不能贴片 |
| 按图贴片 | ① 拖到患者右上胸，② 拖到患者左侧胸、腋下 | 贴片缩放到实际大小并固定，导线保留 | 两片可任意顺序；错位回弹且可重试 |
| 分析前清场 | 点击清场指令 | 协助者双手抬起，之后设备进入分析 | 准备阶段提前清场不让协助者停手 |
| 设备分析 | 等待设备结果 | 屏幕“分析中 / 勿接触” | 分析时不接受恢复按压或电击 |
| 建议电击 | 再次确认无人接触，等设备就绪，按电击键 | 橙色电击键高亮；无夸张电弧、惊跳或“复活”演出 | 未建议、未清场、未就绪均不可电击 |
| 不建议电击 | 不按电击键，立即点击协助者恢复 CPR | 不经过电击步骤，也能完整通关 | 误按键只提醒，不发出电击 |
| 恢复与交接 | 点击协助者恢复 CPR，再让旁人接应并告知急救人员 | 恢复按压，贴片及导线持续连接 | 完成设备操作并不直接通关；必须完成后续帮助 |

结算为“协作完成，继续施救”，明确 **训练流程完成 ≠ 患者已经恢复**。不画患者坐起、微笑挥手或大家停止施救庆祝。

## 美术与同源坐标

- 720×1080 竖屏母构图，暖米色纸纹、鼠尾草绿设备、蓝灰衣物、橙色电击键。
- 背景是本轮 `image_gen.imagegen` 原创生成的社区协作站，不含烘焙人物或可操作设备。仅做等比例缩小与 WebP 编码。
- 人物、胸部准备层、图示、贴片、按钮、毛巾、线缆、提示牌为本轮代码原生教学插图（SVG → PNG），不是伪称 AI 分层提取。人物采用示意性画法，不声称真人动作捕捉或医学级骨骼动画。
- 协助者两帧按压循环与抬手状态拥有相同画布及锚点；减少动态模式保留状态差异。按压周期是表现参数，本关不评估玩家 CPR 频率或深度。
- 贴片接收区域、固定后的渲染位置、线缆端点与设备图示均按本构图新编译。贴片①和②不会只加进度而仍留在工具区。
- 使用公共 `useGameViewport`、`cameraFor` 和 `createCoverCamera`。关键区域覆盖脸、手、胸部操作区、设备、图示与下部工具，无专用镜头补丁。
- 图示的左右始终是**患者本人的左右**：患者右上胸在画面左侧，患者左侧胸在画面右侧。
- 另探索过一张写实水彩人物生成稿，因不匹配本套示意人物风格未采用、未打包；不把它当成已落地素材。

## 通用引擎的最小扩展

`Rules.scenarios` 在开局设置不可由玩家改写的隐藏题设条件；`createRun(pack, scenarioId?)` 的显式参数供测试固定案例。其余动作、阶段等待、条件、物体状态及动画仍用既有引擎。

验证器对每个题设穷举可达状态；禁止情境预先完成可见任务、禁止操作生成情境条件。仅声明情境的处置关允许条件性隐藏目标不进入共同通关集合；原找隐患和既有处置关保持“所有声明目标必须完成”的约束。每个可见任务仍必须在共同通关集合内。

## 声音

复用已存在的 medical 主题和非语言提示音。没有 TTS、AI 朗读、患者语句、语音接口或新联网音轨。浏览器验收始终 `--mute-audio`；音频人工听感 `not_run`，不以静音自动化测试声称“音效已试听”。
