# 细小物体拾取与放置反馈

2026-09-19。未更改关卡安全规则、目标 ID、时限、奖励或素材蒙版。

## 范围与交互合同

- 整场景找隐患：精确蒙版优先，再在小圆形邻域查找最近目标。没有改成包围盒判定，也没有改变共享视口。
- 两个点击收纳关（楼道／应急包）：保留点击后自动收纳，补充“已选中，正在收纳”与提交动作后的“已收好”。它们不是拖放关。
- 通用拖放关（旧配置运行器＋分阶段练习运行器）：选中提示、未对准提示、目标区域实线高亮、松手提示、放空后的说明；有原有教学文案的动作仍优先使用原文案，否则正确动作提交后显示“已放置”。
- 厨房独立运行器和七目标灾害专用运行器本次未改。

## 命中政策

`app/game/display/pointer-hit.ts` 接收 CSS 尺寸对应的世界坐标容差：鼠标6px、触摸10px，最大24个世界单位。精确像素优先；透明区域只在小圆形邻域内查找，不扩大为整张图片矩形。近邻距离相差不超过1个世界单位时不自动选择。前景遮挡和禁用状态仍受原有规则约束。

通用处置关只扩大拖动物体的拾取，不扩大点击按钮的命中，避免把附近点击变成危险操作。

## 目标与判定

`resolveDragPlacement` 同时用于移动预览和松手结算，指针优先，物体中心兜底，兼容抓住物体边缘拖动。只绘制当前物体在当前阶段相关的目标区。金色高亮只表示“此处能接受操作输入”，不表示选择安全或正确；危险分支仍走原有后果，不能自动吸附到安全答案。

再次按下已选中的物体时允许开始拖动，不会误把物体后面的目标区当成放置操作。
