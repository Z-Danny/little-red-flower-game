## 当前规则

1. 拖动母子到干燥楼梯旁。
2. 点击干燥、完好的本户总电闸。外壳不移动，拨杆下拨、绿灯熄灭。
3. 点击手机，母亲实际持机发送位置与人数（仅离线模拟），之后收好手机。
4. 饮用水拖进背包，入包后原物件消失。
5. 手电拖进背包，入包后原物件消失。
6. 泡沫板拖向轻质木板，组合为备用辅助物。两份原材料消失，只保留组合件。
7. 母亲背上已有物资、携辅助物、牵孩子沿楼梯转移，切换到有护栏、遮雨处的屋顶高处。

第3、4、5步可任意交换；第6步可在安全关闸后完成。全部准备就绪才计七项训练完成。未取齐物资时也可以先向屋顶高处转移，安全提前离开不算失败，不发通关奖励；绝不教玩家为收集物件耽误撤离。

## 错误后果与边界

- 将人物拖向窗外洪水或断线区域、选择留在被淹汽车内：当次输入立即进入失败状态，锁定输入、停止计时及发奖。随后播放1.5秒夸张但非血腥的后果示意，再显示重试。
- 家中关闸之后，外部断线与洪水仍然危险，三种错误均不能变成正确路径。火花只画在窗外断线端，不能抓取或修理。
- 普通折叠椅拖动无效，回原位，不改变水位或目标。
- 上涨水位是90秒内饱和的表现曲线，不是真实生存期限。高水位不开放任何游泳、涉水分支。
- 本版的切电前提是手、地面、完好电闸均干燥且不涉水即可到达。潮湿、损坏或需要涉水的现场不能照搬操作。
- 木板与泡沫仅表示就近准备备用浮材；未模拟浮力，未认证承重，不是救生衣，也不是下水许可。
- 屋顶只适用本关已确认完整楼梯、坚固护栏和遮雨处的条件，不泛化为任何建筑都应上屋顶。现实中遵从当地应急部门和专业人员指引。

核对依据：[应急管理部2026-06-23防汛提示](https://www.mem.gov.cn/xw/xwfbh/2026n6y23xwfbh/)、[2025-08-05防汛提示](https://www.mem.gov.cn/xw/xwfbh/2025n08y05xwfbh/)、[中国消防雨季安全提示](https://www.119.gov.cn/kp/zjts/qxzh/2026/55072.shtml)。以上来源支持提前避险、安全断电、远离积水断线、准备水与照明和报告位置；七步顺序是本游戏的条件化训练，不是官方固定通用流程。

## 声音策略

遵从本次确认：人物只有姿态与动作，不添加呼救录音、怪叫、尖叫或AI朗读。音乐、洪流低频、窗外雨声保留；警报、拨闸、发送信息、收纳拉链、转移脚步、错误冲水与成功声为原创程序合成，非实地录音。洪流/雨随压力平滑增强，高处减弱，暂停、隐藏、返回与重试释放或暂停相应声音。

新声音ID：`flood-alert`、`flood-message-sent`、`flood-power-off`、`flood-pack-zip`。替换录音时需保持稳定ID与独立声道，不把环境、人物、音乐烘焙在一条音轨里。没有合适录音时宁缺勿添怪叫。
