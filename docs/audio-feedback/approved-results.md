# 已确认的胜负与结算按钮声音

用户选择：settlement-v2 的前三个（短胜利、短失败、按钮 A）。

| 声音 | 单次时长 | 触发位置 |
| --- | ---: | --- |
| 胜利 | 0.961 秒 | 本局正式完成、出现胜利结算 |
| 失败 | 1.196 秒 | 超时或既定危险操作导致本局失败 |
| 按钮 A | 0.035 秒 | 胜利卡主按钮，以及失败卡的“不服，再来！”、“返回地图” |

## 资产

- 原作者 Kenney；Music Jingles 与 Interface Sounds 两包，CC0。
- 批准 WAV、官方源文件、许可证、ZIP 与 SHA-256：`art-source/settlement-audio-v1/manifest.json`。
- 运行时只用单次 WAV 对应 PCM。按钮的三连播试听版不进入游戏。
- `content/audio/approved-results.json` 随脚本内嵌；同步解码，不等待网络或异步下载。
- 44100 Hz 时 PCM 与批准 WAV 逐样本一致。沿用批准音色、时长和幅度；只受游戏内音量、静音和最终峰值保护控制。

## 触发与收尾

- 识别、收纳、灾害处置使用 HuntSound 的终态接口；实践与旧处置使用 PracticeAudioSession；厨房使用 ResponseAudio。
- 结算时替换此前终态音，收掉玩法背景音；自然播放完毕后保持安静。
- 厨房由真正 complete 触发；先前人物撤离的旧 success 提示不会再提前叠播。
- 暂停、后台、静音、离开或重玩能取消终态音；恢复后不补播上一局。
- 按钮捕获点击一次，支持鼠标、触摸、键盘。导航保留 35 毫秒的点击尾音后释放音源。
- 结算按钮继承当前关卡的音效设置；地图继续使用原地图按钮/奖励设置。
