# 楼道杂物清理：处置学习升级

2026-09-19，按用户确认的方案修改既有 `clear-corridor`，不是新建识别模板，也不是换皮冒充规则改造。

## 玩家流程

1. 无火烟的日常整理，只处理四件自家轻便杂物。点击物品后选择去处，或直接拖放。
2. 三个去处：自家储物间、楼道角落、消防设施前。只有收回自家才记入目标。
3. 两种错误都有具体原因和退回动画；可立即改正，不直接失败、不扣花。取消选择或空场景点击不罚时。消防设施本身不设为可搬动物品。
4. 四件收好只进入待检查状态，不奖励、不通关。点击“检查通道”，播放4.8秒同画风人物试走和三项检查：通道无堆物、出口前无杂物、消防设施前可接近。
5. 检查结束才按原有本机成绩流程结算，首次3花，重玩不重复领取，旧关卡ID及旧存档保持有效。

这是教学演示，不能把人物通过视为现实疏散宽度、出口可开启性或消防设施可用性的专业验收。未表现打开防火门，也不鼓励将常闭防火门保持开启。关内明确有火烟时不为整理杂物耽误避险；不处置他人物品和消防、电气设备。

## 时间与输入

- 保留50秒挑战和共用彩条。最后检查在截止前接受后允许既有演出完成，沿用引擎最后动作保护；50秒时新发起的检查无效。
- 暂停/切后台不推进时钟；失败不发花，重新挑战重置本局。
- 共享规则支持 `hudAction`（带前置条件的点击操作）、皮肤动作支持 `checks`（只读检查点演出）。无关关卡仍走原有入口，不添加关卡专用相机或CSS。
- 原共用收纳相机、规则ID、四件目标ID均保留。底部目标按钮支持触摸和键盘；场景双击式选择与真实拖动使用同一目标解析器。
