## 接入

- 24 个正式关卡共用 `components/game/painted-ui.tsx` 的居中开场弹窗。绿色标题区显示地图中的关卡名，正文显示简短场景介绍，金色主按钮显示该关的开始动作。
- `content/level-introductions.json` 管理每关的 `description`、`startLabel`；新增未知 ID 有“开始挑战”的显示回退，正式地图覆盖由浏览器验收检查。
- 等待开场期间禁止场景点击、计时和活动声音；点击开始才进入原游戏流程。弹窗支持键盘焦点循环、Enter 开始、Escape 返回和资源准备状态。
- 三枚 HUD 图标是用户选定的提示、暂停、返回图片，按钮保持至少 44×44 CSS 像素。原提示展开、暂停和返回行为由各玩法引擎管理。
- 倒计时移动到 HUD 最顶部，金色填充配小红花花瓣指针。原 12 个限时挑战、厨房训练及原本显示倒计时的处置训练使用同一个 `CountdownBar`。原正计时、水位与温度风险显示保留各自含义。
- 所有弹窗的继续、进入、返回、重玩、重置按钮去掉箭头装饰。场景 HUD 中的返回图标保留用户选定造型。

## 素材与布局

- 运行资源：`public/ui/painted-v1`，7 组透明 PNG/WebP，总运行 WebP 约 270KB。
- 原稿、生成提示词和 SHA：`art-source/painted-ui-v1/{README.md,manifest.json,prompts.json}`。
- `modal.webp` 960×875，无文字无箭头；文字和按钮是真实 DOM，集中由 `app/painted-ui.css` 定位。
- 进度条空槽和满条均 1600×89。固定空槽，只裁切满条内部填充；内槽 x=3.9%–96.1%、y=34%–76%，满条图上移 4.5% 对齐；指针尖端位于轨道 y=55%。
- 剩余比例来自引擎实际 elapsed/seconds，误点扣时、暂停、后台冻结和截止判定沿用原逻辑。紧迫阶段仅改变填充颜色，不引入第二套计时器。
- `app/painted-hud.css` 只处理 HUD 排列，放在各引擎样式后加载；不修改场景尺寸、蒙版、命中坐标、相机或规则。
- `scripts/export-offline.mjs` 直接内嵌上述 7 个明确路径的图片及两份共用 CSS；运行时不依赖工作区或图片服务器。
