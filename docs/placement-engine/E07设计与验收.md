# E07《晃动开始了》首关试做

用户原案：高层住宅客厅，两阶段，震中 12 秒＋震后建议 45 秒；目标为震时就近避险、震后有序撤离。画面按补充要求改为低饱和冷灰蓝、阴天漫射光，减弱明媚阳光与光斑。

## 试玩方式

1. 打开批次目录下的 `开始试玩.html`，点击“开始试玩”。
2. 把沙发上的绿色坐垫拖到人物头颈；把人物拖到桌下。也可以使用画面下方的点选按钮。
3. 按住桌腿附近“手抓牢”或下方同名按钮 1.5 秒。提前松开、移出、暂停、切页都会取消本次长按。
4. 抓牢后保持到 12 秒结束；若没有完成三个目标，会出现“重新练习震时避险”。
5. 震后点击“观察周围”，再关燃气、把鞋放到脚部、把应急包放到人物背部。关火、穿鞋、带包可交换顺序。
6. 把人物拖到入户门后的楼梯区域。结算进入冷调开阔地画面。

“45 秒”是节奏参考，超时仍可完成训练。时间与关卡进度不代表真实地震时长或建筑已安全。

## 交互与音效

| 对象 | 正确/主要交互 | 对应动作音效 |
| --- | --- | --- |
| 坐垫 | 拿起、拖到头颈，随人物姿态移动 | 织物提起、贴合摩擦 |
| 人物 | 移到桌下、沿楼梯撤离 | 跪伏衣物摩擦、连续脚步 |
| 桌腿 | 长按抓牢 | 手与木材接触、抓牢确认 |
| 观察按钮 | 震后确认环境 | 简短观察完成提示 |
| 燃气开关 | 本情境安全可达时关闭 | 旋钮咔嗒 |
| 鞋 | 穿好鞋 | 鞋底落地 |
| 应急包 | 携带轻便包 | 背带与织物摩擦 |
| 电梯 | 错误选择后标红禁用 | 开关阻止音 |
| 贵重物返回 | 中断并提示余震 | 短促金属警示 |

以上九个交互对象都另有拿起/按下、未命中、条件不足、取消/回位配置。所有十四条动作都有对应声音；另有震中低频环境声和震后转换提示。完整文件及触发进度见每关的 `音效对应表.json`。

错误路径覆盖：震中冲楼梯、门框、阳台、高柜；震后乘电梯、返回取贵重物。风险预览不表现人物伤亡，错误操作中断后仍可继续训练。电梯禁用仅限本轮，重置会恢复。

## 对原案的具体化与适用条件

- 为减少位置歧义，关内八个接收区域互不重叠。桌面绘制在跪伏人物前方，站立人物位于桌旁前景；头颈坐垫按姿态切换跟随偏移。
- “保持”实现为抓牢确认后锁住本阶段人物移动，直到晃动结束。不是要求玩家按足整个 12 秒；1.5 秒模拟抓牢动作。
- 阶段二观察反馈明确本情境“暂无明显坠落危险、无燃气异味、开关近身安全可达”。没有把“冒险关阀”或“返回取包”设计为正确操作。
- 坐垫是身边可用物；文案提示不得为找物延误避险。鞋与轻便包是此情境的训练目标，不是现实中优先于生命安全的绝对步骤。
- E07 使用独立放置关卡与阶段配置，不套用厨房烟火压力模型；厨房旧关逻辑保持原有语义。

## 官方来源核对（2026-09-12）

- [应急管理部、中国地震局地震安全知识](https://app.www.gov.cn/govdata/gov/202505/13/528831/article.html)：室内就近伏地、遮挡、手抓牢，避开玻璃和悬挂物；室外寻找开阔地并远离高楼、电线杆、广告牌。
- [应急管理部室内避震方法](https://www.mem.gov.cn/kp/zrzh/202102/t20210204_379654.shtml)：强调牢固家具、避开悬挂物与震后有组织撤离，具体做法依所在环境区分。
- [应急管理部积石山地震烈度图](https://www.mem.gov.cn/xw/yjglbgzdt/202312/t20231222_472849.shtml)：作为参考事件来源。本关没有复刻具体村镇、住宅或灾损程度。
