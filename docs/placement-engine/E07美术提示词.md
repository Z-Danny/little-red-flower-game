# E07 美术提示词与素材记录

本轮使用 Codex 内置图像生成工具生成和编辑，未使用外部 CLI。最终选择的九张原图保存在交付目录的 `美术素材/`，运行配置内嵌同一组图像。以下为整理后的完整可复用提示词；重新生成不会保证像素完全相同，需要重新检查锚点、尺寸、透明度和遮挡。

## 装配和验收

- 背景与室外图等比映射到逻辑画布；人物原图的透明边距通过 `assets.*.frame` 采样，不重新修改原始像素。
- 站立人物帧为 `(340,41,405,1344)`；跪伏人物帧为 `(42,112,1362,860)`。换图后必须重测，不能把这些帧无条件套用新图。
- 餐桌深度 8，桌下人物深度 6；站立人物深度 10。坐垫随姿态改变偏移，桌腿的长按标牌完成后隐藏。
- 放大检查真实透明度。带有画出来的棋盘格或白色矩形的“透明图”不合格。
- 当前应急包和燃气/火焰复用项目既有素材；观察、电梯和贵重物入口使用原生界面标记，不伪称为新生图。
- 最终选中原图清单与 SHA256 见交付 `美术素材/素材清单.json`。生成结果具有随机性，提示词不能代替运行画面的遮挡和落点验收。
