## 动画

`app/title-screen.css` 的 `--cover-cycle: 2.8s` 控制花朵、标题光泽与主按钮的共同节奏。花朵只正向播放：花苞轻颤至周期的 6%（约 0.17 秒），初开与半开分别在 26% 和 48% 达到完整帧，70%（1.96 秒）完全盛开。盛开只停留 0.84 秒，周期结束后直接开始下一轮花苞，没有反向收拢或额外等待。标题、八粒花粉与主按钮围绕 70% 的盛开时刻联动：花粉散开，标题短促放大至 1.04 倍并增强金光，笔画内部掠过一道扫光；可用主按钮轻浮并亮起金边。次按钮没有循环提示，所有菜单按钮保持无箭头。按下按钮时缩小至 0.96 倍、下压 3px，反馈优先于循环动效。

首次进入时，背景和全部封面素材完成图片解码后一起开始计时。标题以 650ms 放大落定并轻微回弹，之后持续浮动；标题预留固有比例以避免加载时跳动。湖面六处微光采用与背景相同的比例和裁切，始终位于夕阳倒影附近。页面隐藏时暂停所有图层及伪元素动画，回到页面继续；离开首页时组件卸载。系统开启“减少动态效果”时固定显示盛开的花朵，关闭全部封面动画并隐藏流光、花粉、落叶与水面碎光。

十片红叶分成四片近景与六片远景：近景 30–35px、10.5–12.2 秒飘落，远景 15–19px、15–18 秒飘落。沿途斜向漂移、翻转，叠加共同的 2.8 秒阵风，在离开画面前淡出。红叶位于标题、花朵与按钮下层；全部装饰层均不拦截点击。粒子及扫光蒙版复用本地透明 PNG，离线版同样可播放。

配置入口：`content/journey-home.json`；视图入口：`components/game/journey/title-screen.tsx`。地图品牌名和浏览器文档标题已改为“这片儿没我不行”。存储键和关卡 ID 保持原值。

进入地图时播放 360ms 的背景推进与前景退场，开始和继续共用这一转场。只有开始条件满足、重新开始确认且存档重置成功后才触发；取消确认或重置失败时保留封面与错误提示。转场期间两个按钮禁用，同步引用阻止连续点击重复写入探索位置。系统开启减少动态效果时直接进入地图。音频解锁仍发生在用户交互调用中，不延迟到动画完成后。

## 生成记录

素材通过内置 imagegen 从已确认封面拆分、清理及补绘，未改用外部 API。提示词和资产 SHA-256 清单保存在 `art-source/cover-v2/`。原始 PNG 本机也存于该目录并受仓库现有大图忽略规则保护。制作后的 PNG 只做透明留白裁剪和分辨率适配，背景和花朵图集保留生成原文件。

## 本地验证

```sh
pnpm typecheck
pnpm test:journey
pnpm test:leaderboard
pnpm build
BASE_URL=http://127.0.0.1:3000 node scripts/test-cover-browser.mjs
pnpm export:offline
OFFLINE_FILE=outputs/本地离线版/小红花应急行动.html node scripts/test-cover-browser.mjs
```

为了兼容现有导出和分发脚本，离线文件继续使用原文件名，打开后的页面标题与美术均为新名称。导出器将全部分层 PNG 和动画 CSS 内嵌到最终 HTML，无外部素材请求。

浏览器脚本使用隔离存档、静音 Chromium，并在 finally 中关闭。验证覆盖四种视口（320 × 568、390 × 844、430 × 932、1440 × 900）、44px 点击区域、回归玩家按钮至少 18px 的间距、减弱动画、标题登场与持续动态、花朵仅正向开花且跨周期直接从花苞重启、水面微光/花粉/主按钮提示的暂停恢复、开始/继续的 360ms 转场及快速重复点击。首页校验无记录时只显示“开始游戏”，有效零花朵探索仍可继续，其他玩家、无效时间、未知或锁定关卡的书签不会被当成可继续记录。存档用例还覆盖跨标签页书签更新、新游戏取消与确认、确认时玩家变更导致的重置失败、其他玩家记录保留。返回封面使用真实地图首页按钮，并核对成绩与探索位置字节保持不变；重载只用于持久化或隔离玩家夹具验证，不访问用户浏览器存档。报告与截图位于 `verification/dev/` 和 `verification/offline/`。真实手机触摸和人耳音效验收：`not_run`。

先完成构建、再运行开发页测试、再导出并验证最终离线 HTML；不要把开发页测试与 `export:offline` 并行运行，因为导出过程会重写生成模块并触发开发服务器热更新。可通过 `PLAYWRIGHT_MODULE` 和 `BROWSER_EXECUTABLE` 指定本机 Playwright/Chromium 路径，通过 `COVER_TEST_OUTPUT` 指定报告目录。
