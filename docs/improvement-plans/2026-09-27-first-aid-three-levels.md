# 急救主题三关互动设计方案

- 文档日期：2026-09-27
- 版本：v1.0 · 统一整理稿
- 状态：设计草案，待医学审核及制作确认
- 范围：基础生命急救、意外伤害急救、突发疾病应急各一关；第三关采用互动增强版。
- 本文整理既有讨论，不代表已经完成医学审定、素材制作、程序实现或实际试玩。

## 一、整体设计要求

### 1. 主题与定位

三关归入“急救救护”主题。地图入口建议延续现有天空浮岛、绘本建筑和木牌风格；是否增加第四个主题岛，在接入阶段确认，不修改现有三个主题及已有成绩。

本项目为知识与流程模拟，不是医学诊断工具，不提供急救技能认证。首批场景限定成人，不混用婴幼儿、溺水、特殊外伤等流程。

### 2. 共用体验结构

进入场景 → 观察与行动 → 状态变化与纠错 → 持续帮助或专业交接 → 训练结算。

三关都以人物和场景物件互动为主，不做成选择题、连续点下一步或找隐患题卡。点击、拖放、持续操作、节奏操作必须服务于学习目标，不能为了凑步骤延误关键行动。

### 3. 共用规则与边界

- 不套用找隐患关的50秒失败、误点扣5秒规则，不设置虚构生命值。
- 游戏演示时间与现实处理时间分开，压缩演出必须明确说明。
- 关键求助入口不能藏在收集、找物、拼图或完整检查之后。
- 错误可纠正；不给冒险操作加分，不要求先犯错才能完成训练。
- 通关代表完成本段模拟，不代表伤者痊愈或玩家已经掌握真实急救技能。
- 中国大陆版采用模拟120呼救，不调用真实拨号、不发送真实位置或医疗信息。
- 医学步骤、动作姿势、错误提示及通关条件须经过有资质的急救人员审核后启用。

### 4. 三关总览

|类别|关卡名称|情境|核心互动|学习重点|
|---|---|---|---|---|
|基础生命急救|广场上的紧急呼救|成人突然倒地|人物检查、协作呼救、按压节奏、AED操作|及时启动帮助并配合设备|
|意外伤害急救|打翻的热水杯|成人前臂热水烫伤|离开热源、操作水龙头、定位冲洗、覆盖伤处|及时冷却，理解现实处理时间|
|突发疾病应急|突然说不清的话|家人出现疑似脑卒中表现|人物观察、呼救、记录、家人协作、交接|识别异常后立即求助，不自行治疗|

## 二、第一关：广场上的紧急呼救

### 1. 定位与学习目标

- 类别：基础生命急救。
- 目标：认识成人倒地后的紧急识别、呼救、CPR与AED配合流程。
- 互动特点：人物协作＋节奏操作＋设备操作。
- 难度定位：三关中操作组合最复杂，需逐阶段提示，不能默认玩家有专业训练。

### 2. 情境与适用边界

社区广场，一位成人突然倒地；附近有一名可以协助的路人，以及可用AED。

本题明确成人无反应、没有正常呼吸或仅有异常喘息。不把所有倒地都判为需要按压，不加入公众摸脉搏考核。首版限定公众成人急救认知；特殊病因、年龄和专业施救流程另行设计。

### 3. 场景、人物与道具

|元素|用途|制作要求|
|---|---|---|
|倒地成人|反应、呼吸与按压示意|身体比例与动作姿势须专业审核|
|协助路人|取AED、参与协作|有明确行动和返回过程，不凭空出现设备|
|手机|模拟呼救、免提联络|呼救入口明显，不解锁、不输长号码|
|AED及柜体|设备取用与分析提示|设备状态与操作反馈保持一致|
|电极片|按设备图示放置|准确图示、清楚落位反馈|
|地址标识|辅助说明现场位置|不能变成先找到才可呼救的钥匙|

### 4. 互动流程

|阶段|玩家操作|人物／场景反馈|完成依据|
|---|---|---|---|
|识别|点击人物，触发检查反应与呼吸示意|呈现本题限定的异常状态|识别示意完成；不考摸脉搏|
|呼救协作|点击手机模拟120、指派路人取AED|免提通话状态建立，路人离开取设备|呼救已启动、协作已指派|
|开始帮助|按图示定位双手，进入节奏操作|人物姿势与按压动画响应输入|仅记录游戏内动作与节奏|
|设备到达|开机，按设备图示放置电极片|设备进入分析提示状态|按设备流程判定准备状态|
|安全配合|按提示确保无人接触患者|按情境展示建议电击或不建议电击|分析和电击阶段的安全条件满足|
|继续帮助|按设备提示恢复CPR|持续救助，专业人员到场接手|本段模拟与交接完成|

医学流程、手位、节奏及设备操作细节在分镜制作前再核对；不能用本文概述替代设备说明或专业培训。

### 5. 分支与纠错

- 检查、呼救和CPR衔接不能被一串小游戏拖长；不等待AED返回才允许开始帮助。
- AED到达后，不必凑够连击次数才能使用。
- 电极片位置错误时给局部纠正，不演出夸张伤害。
- 明确区分建议电击和不建议电击；不建议电击不等于无需继续帮助。
- 分析与电击阶段的接触状态必须可见，避免玩家不明白为何需要离开接触区域。
- 节奏偏差提示只指向游戏输入，不声称测到了真实按压深度、力度或施救能力。

### 6. 完成条件与结局

完成本题要求的呼救、帮助、设备配合和交接，进入“本段训练完成”。不以伤者苏醒、固定次数按压或固定次数电击作为成功条件。

结局：专业人员接手，玩家退到旁边。提示“游戏模拟不替代正规急救培训”。

### 7. 美术、动画与声音

- 延续绘本风格，但姿态不能因卡通化而失真。
- 路人取设备、开机、贴片、离开接触区、恢复帮助形成连贯动作。
- 用短文字和设备提示音说明状态；静音时信息完整。
- 不生成AI朗读，不制作伤者突然跳起庆祝或惊叫惩罚。
- 明确现实使用应遵循AED设备提示；游戏图文表达不能伪装成完整真实设备训练。

### 8. 制作清单与验收要求

制作：场景母版、人物动作组、路人取机动画、手机状态、AED各状态、电极片与落位区、专业交接画面、医学依据表与状态图。

验收：
- 呼救可及时启动，AED取用不阻止开始帮助。
- 按压与AED流程之间能正确切换。
- 建议电击和不建议电击分支均有测试。
- 不能边接触患者边完成要求清场的操作。
- 暂停、后台、重试不产生积压输入或重复计数。
- 结算不保证抢救成功，不重复发奖。

## 三、第二关：打翻的热水杯

### 1. 定位与学习目标

- 类别：意外伤害急救。
- 目标：理解停止继续受热、及时冷却、保护伤处及后续求助。
- 互动特点：物件操作＋持续冷却＋处理状态变化。
- 难度定位：三关中最直观的操作入门关。

### 2. 情境与适用边界

家庭餐厨区，一位成人前臂被打翻的热水烫伤，旁边有可用水槽；衣袖未黏附伤处。

不混入化学烧伤、电烧伤或大面积严重烧伤。若扩展这些情况，需另立医学流程。现实需要就医的判断与文案须专业审核，不以游戏外观替代伤情评估。

### 3. 场景、人物与道具

|元素|用途|制作要求|
|---|---|---|
|受伤成人|离开热源、前臂冲洗|手臂与伤处位置连续，不瞬移|
|热水杯、桌面|交代受伤原因|不鼓励玩家徒手清理滚烫物品|
|水龙头、水槽|流动凉水冷却|水流与手臂接触关系可见|
|非粘连覆盖材料|冷却后保护|轻覆效果，不紧勒、不黏贴伤面|
|手机|后续求助提示|不与冷却形成不合理互斥|
|普通药膏、粘性创可贴|可选纠错|不是必用道具，不强迫错误尝试|

### 4. 互动流程

|阶段|玩家操作|人物／场景反馈|完成依据|
|---|---|---|---|
|停止受热|将人物移到水槽旁|停止接触热源，伤处仍可见|离开热源示意完成|
|开始冷却|打开水龙头，将前臂定位到水流下|流动凉水接触伤处|冲洗位置正确|
|持续冷却|确认位置，观看压缩演出|显示时间压缩说明与现实时间要求|完成冷却过程示意，不测真实疗效|
|保护伤处|冷却后放置合适覆盖材料|轻覆伤处，人物保持稳定|覆盖材料与位置正确|
|后续处理|查看手机求助、就医提示|明确初步处理并不代表痊愈|阅读边界提示，完成本段训练|

沿用前期方案：现实冷却知识点为流动凉水20分钟；制作前核对采用指南的具体表述。演出可以缩短或跳过，但不能省略“这是时间压缩示意”的说明，不要求玩家真实等待20分钟。

### 5. 分支与纠错

- 手臂移出水流时反馈冲洗位置变化，不用生命值扣分。
- 普通药膏、粘性创可贴等放到新烫伤处时阻止操作并解释，不通过惩罚画面教学。
- 不设置冰敷、涂牙膏、挑破水疱等正确操作。
- 黏附伤处的衣物不能被设计成应强行拖下的物件；首版题设排除该情形。
- 冷却演出跳过只改变展示时长，不能暗示现实可以省略冷却。

### 6. 完成条件与结局

完成离开热源、冷却示意、合适保护及后续提醒。结局为“已完成初步冷却与保护”。

人物可以逐渐平静，伤处不能瞬间恢复；不以疼痛值归零表示痊愈。需就医的情形不通过游戏中的“完成”标记豁免。

### 7. 美术、动画与声音

- 伤处表现克制，不用血腥或夸张皮肤变化。
- 水流、前臂位置、覆盖材料之间的关系清楚。
- 使用流水、开关、物件轻放等声音；不加入惊叫或AI朗读。
- 现实时间提示必须可读，不能仅一闪而过。

### 8. 制作清单与验收要求

制作：餐厨场景、成人站姿与冲洗姿态、水流层、覆盖材料、手机提示、冷却转场、初步处理结局、医学依据表与状态图。

验收：
- 离开热源与开始冷却之间无收集解谜。
- 冲洗位置反馈准确，提示不遮挡伤处。
- 时间压缩前后均不造成“冲几秒即可”的误解。
- 错误用品不能取得正确进度。
- 暂停、后台、重试能恢复正确阶段。
- 结局无瞬间治愈、无错误治疗暗示。

## 四、第三关：突然说不清的话（互动增强版）

### 1. 定位与学习目标

- 类别：突发疾病应急。
- 目标：识别疑似脑卒中信号，立即呼救，协作待援并交接信息。
- 互动特点：人物状态观察＋手机持续使用＋家人协作＋现场变化。
- 难度定位：观察与协作型关卡，不考诊断、不考自行治疗。

### 2. 情境与适用边界

家庭客厅，一位原本正常交谈的成人突然说话含混，并可能出现面部不对称、一侧手臂无力。另一名家人在旁。

任何一个已发现的疑似信号都允许立即模拟120呼救，不要求收齐三个症状。首版保持患者有反应、正常呼吸，不突然叠加CPR考核。

“最后一次正常时间”与“发现异常时间”分开记录；信息不确定允许如实报告，不要求猜测。医学边界与文案须复核。

### 3. 场景、人物与道具

|元素|用途|制作要求|
|---|---|---|
|出现异常的家人|微笑、抬臂、交流与持续观察|表现克制，不做滑稽模仿|
|协助家人|提供信息、提醒、迎接救援|有明确职责，避免让玩家离开患者去找物|
|手机|模拟120、免提、记录、交接|同一设备持续使用，不拆成无关小游戏|
|时钟|辅助区分当前与历史时间|不把当前时间误当发病时间|
|地址信息|报告位置|不因没找到卡片而阻止呼救|
|水杯、药盒|可选纠错|不要求先喂再纠正|
|门、玄关小凳与鞋子|家人协助迎接|整理不是救援进入的硬门槛|

### 4. 互动流程

以下8个互动点不是强制顺序任务。观察为可选补充，呼救立即可用；协作与信息整理在呼救后进行。

|互动点|玩家操作|人物／场景反馈|流程地位|
|---|---|---|---|
|面部观察|点击人物，触发请微笑的示意动作|出现面部不对称，提示可以立即呼救|可选观察，不锁呼救|
|抬臂观察|点击抬臂动作提示|人物自主尝试抬臂，一侧无力或下落|可选观察，不拖拽患者肢体|
|紧急呼救|点击手机、模拟120、免提|通话已建立，可继续观察现场|关键主线|
|询问时间|点击家人了解情况，点击时钟辅助记录|区分发现异常与最后正常；允许不确定|通话中／呼救后补充|
|提醒不要喂水|家人拿水时点击提醒，放回杯子|家人改为提供信息或协助迎接|可选事件，不强迫犯错|
|指派迎接|点击家人，再点击玄关|家人打开入口，必要时移开小物件|可选协作，不阻挡接手|
|持续关注|点击患者查看反应与呼吸表现|按模拟调度提示报告变化|主线等待阶段，无定时点击惩罚|
|现场交接|向到场急救人员展示手机记录|家人引导，专业人员接手|主线完成点|

核心流程：

开场出现异常 → 立即呼救（可选补充观察）→ 按提示报告并陪伴 → 专业人员到场 → 交接。

时间记录、家人协作、可选纠错在此主线内发生，不构成集齐道具才能求助的任务链。

### 5. 分支与纠错

- 开场已有说话异常，因此直接呼救是有效路径，不因未看脸或未抬臂扣分。
- 不让玩家拖动患者手臂、连点使肢体恢复，或要求患者走路验证。
- 喂水、喂食、自行给药等操作给予阻止与简短解释，不生成呛咳惩罚剧情。
- 不加入掐人中、扎手指等正确操作。
- 不清楚的症状或时间可记录“不确定”，不能强制编造。
- 患者症状若出现暂时缓解，仍维持呼救待援，不奖励取消求助。
- 入口整理属于协作表现，不能让“还剩一只鞋没移开”阻挡专业人员接手。
- 记录没有完全填满时也能交接，避免“完美资料”高于及时求助。

### 6. 完成条件与结局

核心条件：已模拟呼救；已如实报告已知异常与位置；保持关注并完成专业交接。时间信息允许不确定；其他观察与协作不是额外强制医疗步骤。

不以收齐三个症状、获得明确诊断、收完所有道具或患者恢复正常为通关条件。

结局文字：“及时呼救，清楚交接，为专业救治争取机会。”患者仍在接受帮助，不站起庆祝。

### 7. 美术、动画与声音

- 同一人物呈现交谈、尝试微笑、抬臂、接受帮助等状态，服装与脸部身份一致。
- 手机被拿起、杯子放回、入口打开、家人迎接、急救人员进入构成可见场景变化。
- 用文字说明语言异常，不用滑稽口音、AI朗读或夸张神情模仿。
- 等待阶段可以有细微呼吸和视线变化，不设置每几秒必须点击一次的扣血机制。
- 不使用闪烁生命值、催促找全症状的倒计时或保证治愈的演出。

### 8. 制作清单与验收要求

制作：客厅与玄关场景、患者同源动作组、家人协作动作、手机通话与记录状态、时钟与地址信息、水杯纠错事件、迎接和交接演出、医学依据表与状态图。

验收：
- 开场直接呼救、观察一个症状后呼救两条路径都可完成。
- 不强制做完脸、手臂、语言检查。
- 不确定时间、未填满记录不阻挡交接。
- 可选递水事件未发生时也可通关。
- 家人迎接不造成患者无人陪伴的必经任务。
- 暂时缓解不引导取消呼救。
- 不同操作顺序不会卡住通话、重复派遣或重复生成急救人员。
- 全程无自行诊断、自行用药、立即痊愈暗示。

## 五、共用技术与交付要求

### 1. 架构

- 走项目处置类工作流；先评估现有配置型互动框架的能力，再决定需要新增的公共能力。
- 不照搬厨房火势、温度计、人物恐惧或危险解除判定。
- 规则、文案、皮肤、动画、声音与统一视口分离。
- 不增加关卡专用相机或用于掩盖构图问题的CSS。
- 新构图需配套同源人物、物件、蒙版、锚点与结局，不能套旧坐标。
- 新关默认不启用，不复制历史题卡或测试夹具作为生产模板。

### 2. 输入与无障碍

- 手机触控优先，兼容鼠标；按钮和关键操作区域易于辨认。
- 节奏、拖拽等交互应提供适当辅助方式；不以手速或精细运动能力衡量知识掌握。
- 提示与HUD不遮住关键动作；减少动态偏好下仍可理解状态变化。
- 静音可完成全部学习流程，颜色不是唯一反馈渠道。

### 3. 存档与奖励

- 新关分配独立稳定ID，实施时检查重名与顺序；不覆盖现有关卡及成绩。
- 沿用项目首次完成奖励及重复完成不重复领奖的约定；实施前核对现行模型。
- 急救训练结算不显示现实能力认证或保证救治成功。
- 正常解锁与首页全解锁测试模式分别验证，不伪造完成记录。

### 4. 验收门禁

1. 医学依据与专业审查：每项操作、前置条件、禁忌、结局和动画逐项确认。
2. 规则测试：正确流程、不同合理顺序、错误分支、提前求助、重复输入和奖励幂等。
3. 生命周期：暂停、后台、恢复、重试、退出的计时与音频状态正确。
4. 画面适配：小屏手机到桌面，人物、关键道具、目标区域和HUD不互相遮挡或裁切。
5. 工程检查：完整单测、类型检查、生产构建。
6. 最终交付：重新导出HTML并记录SHA-256，验证实际导出文件而非只验证源码。
7. 浏览器测试：隔离上下文、静音、finally关闭，不读取用户个人浏览器记录。
8. 真机测试与人耳试听单独记录，未做必须写not_run。

## 六、制作顺序建议

先完成三关医学依据表与状态图，再制作灰盒交互；灰盒通过后才生成正式素材。

建议先做第二关验证物品操作与状态变化，再做第三关验证非线性呼救和家人协作，最后做第一关的节奏与AED安全状态。此顺序仅为开发安排，不强制改变地图展示或学习顺序。
