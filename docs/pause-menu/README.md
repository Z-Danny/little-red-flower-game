# 统一暂停纸卡

2026-09-15，按用户确认的绘本便笺与金色书签效果图接入。

## 当前设计

- 所有正式播放器使用 `components/game/pause-menu.tsx` 和 `app/pause-menu.css`。
- 纸卡上限 310 CSS px，正文按内容撑高；找隐患和收纳关不放重复提示，因此更矮。
- 仅文字提示（适用关卡）、声音总开关、「重新开始」；无已暂停顶栏、红花、继续按钮、重来图标、返回地图、全屏或高级音量。
- 文字提示由当前规则及已完成动作计算。厨房区分燃气、锅盖、撤离，配置处置区分可执行动作和等待阶段；不会将截图中的厨房文案套给别的关卡。
- 圈选与收纳关仍通过 HUD 灯泡查看剪影。

## 行为

- 引擎继续负责暂停计时/风险/动作和声音；纸卡不创建另一套规则时钟。
- 再次点击原暂停按钮、点击纸卡外或 Escape 恢复；纸卡内部点击不会穿透场景。
- 原 HUD 返回按钮在暂停时保持可用，直接返回地图。
- 「重新开始」立即重开本局，清除本局目标/动作/计时；保留通关记录和已获得小红花。
- 声音总开关覆盖当前播放器的全部声音后端，暂停期间不会因开关而恢复计时。
- 厨房原键盘辅助操作保留为场景内键盘焦点入口，不在暂停内提交动作。

## 素材与离线

- 用户确认图和生成提示词：`art-source/pause-menu-v1/`。
- 无字纸卡与无字书签素材：`public/ui/pause-v1/`，所有文字/按钮/开关为真实 DOM。
- 导出器内嵌纸卡 CSS 和两张 WebP，不依赖外部网络。
