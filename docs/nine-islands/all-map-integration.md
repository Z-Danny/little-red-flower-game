## 数据和渲染边界

- `content/island-level-maps.json`：九图的本地图片路径、真实尺寸、SHA-256、场景坐标和占位文案。运行 `node scripts/sync-island-map-content.mjs`，从七图制作记录和网络/食品标注生成；生成前检查全部 ID 唯一，覆盖原有 32 个地图节点及 28 个草稿，图片哈希与真实尺寸一致。
- `app/game/journey/island-scenes.ts`：创建只用于选关显示的地图构图；`island-previews.ts`：28 个只读占位的介绍索引。
- `components/game/journey/island-level-select.tsx`：每岛只绘制一幅底图，复用 `MapScene`、木牌、花苞和原有操作区。统一的上下木牌布局避免左右建筑的标题争用同一空隙，底部左侧入口的木牌向上展开避开返回按钮；不设置关卡专用相机或缩放。
- 新构图不复用旧图的天气、雾区、路径高亮和特效锚点；各图保持自己的原生宽高比，校园是 724×2171，其他是 724×2172。旧关卡背景和关内统一视口没有换皮或修改。
- `content/journey-map.json`、旧关卡规则、前置解锁、存档及奖励模型不变。原版地图仍保留用于既有种花演出，演出结束回到新的岛内选关页；不把新选关坐标写回进度图。

## 验收入口

单测与检查输出在 `outputs/nine-islands-all-integration/`。最终游戏先导出到该目录的 `game/`，在最终 HTML 上用 `scripts/test-nine-islands-browser.mjs` 验证九张底图、60 个真实入口点选、预告禁用、原有关卡启动/返回、存档不变及临时全解锁边界。另以 `scripts/test-island-scroll-lock-browser.mjs` 检查手机触控和纵向地图滚动，并用 `scripts/test-island-map-layout-browser.mjs` 检查六种视口中的全部九图，木牌不重叠、不越出画框且文字可读。浏览器均隔离、静音、离线，`finally` 关闭；真机触控和人耳试听 `not_run`。
