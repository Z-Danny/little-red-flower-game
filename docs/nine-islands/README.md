## 使用方式

首页“开始游戏”（以及继续游戏）直接进入九岛地图选择；不再先进入原四章场景。点击任意可见岛屿立即进入该主题的完整关卡选择页，点击木牌关卡打开原有说明并按原规则开始。关卡退出返回主题关卡页；返回按钮逐级回到选岛、首页。成功结算仍保留原种花演出，演出结束后回到主题关卡页。选岛界面固定为9:16竖屏，在手机、桌面和横屏窗口中按比例居中完整显示，不横向展开。岛屿下方的名称说明、进度、查看按钮、箭头按钮、圆点导航和提示文字全部移除；木牌仍直接保留在原图中。

手机左右滑动、电脑按住拖动，岛屿跟随手势沿圆弧移动；松手后停靠。点击中央或两侧露出的岛屿直接进入该主题关卡选择页。空主题点击后明确显示筹备中。无自动轮播。键盘方向键、Home / End 和 Escape 保留为无障碍操作，页面不显示额外导航控件。

圆弧模型在 `app/game/journey/island-orbit.ts`；每个岛屿绕公共圆心旋转，内部反向旋转保持图像与文字竖直，而不是在两点之间直线平移。中间岛屿最大，两侧略缩小、上抬。减少动态效果设置会禁用吸附过渡，手动拖动仍跟手。触控捕获转移、取消手势和拖动后的点击抑制都有最终HTML浏览器回归。

岛屿宽度从画框的90%降为70%（缩小约22%），木牌文字和图片保持原样。岛内关卡选择现直接复用原版 MapScene，恢复原底图、原坐标、原木牌、花苞和特效；移除上一版新画的弯曲路径和重排木牌。九岛数量、分类与各岛关卡ID不变。一个岛若有来自多个旧地图的关卡，用岛内场景标签切换，只显示属于本岛的节点，不把关卡重新划回旧分类。网络、食品仍为空主题，不虚构原地图或关卡。美术来自原游戏资源，不把附件中描述的待建主题当作已经实现的玩法。仅改变导航和选择界面，不改变任何关卡相机、场景坐标或统一视口。
