## 画面与素材

- 全部人物仍为中国人。沿用四张中国人物母版，没有换人或添加其他国籍角色。
- 全屏底景使用共享 `sceneCamera(..., true)` 的等比cover；中间同源完整构图使用同一模块的contain变换、上下柔边融合，保住所有人物与道具。四角都有画面，没有旧版侧衬或下方阅读面板。
- 手机占满可视区域；桌面保留正常竖屏。继续调用 `app/game/scene-hunt/viewport.ts` 的 `phoneFrame`，没有新增关卡专用相机。
- **明确实现边界**：这不是把单张旧图强行cover后裁掉人物，也不是一张新生成的加长母版；是同源底景cover＋完整主体叠层的运行时构图。新构图生成请求返回503/model_not_found，没有可用输出，不伪称生成成功。
- 五种用品按现行中国人物母版重新标定源坐标、人工描绘alpha多边形，编译为同源透明精灵和剪影。桌面以连续的同源木纹在运行时合成，急救包和五件物品为独立前景；物品收起即隐藏精灵，不留下原图中的重复物品，不伪称AI修复或自动语义分割。
- 主体人物/专业交接保留同源母版；人物不是全骨骼动画。CPR的手势与光圈是交互示意，不伪称真实施救动作或力度测量。
- AED/电极小道具复用本项目4-8的既有设备素材，不复制其整关逻辑或人体坐标；贴片交互是独立设备示意图，不把未经审查的照片当操作依据。
- 美术编译记录：`art-source/first-aid-comprehensive/fullscreen-v3/compile.json`。记录母版SHA、实际人工alpha多边形、输出SHA、失败的生成请求。

## 交互与状态约束

- 规则ID `first-aid-comprehensive`、前三幕语义、原三项结算和禁用状态不变。按用户的新互动需求显式将rules版本提升为2，新增interaction字段；不是偷偷以换肤改变规则。
- 呼救与取AED可交换指派次序；呼救启动后即可开始本题帮助，不必等同伴返回。AED用活动时钟表现短暂取用过程，没有按压点击数解锁门槛。
- 暂停/切后台冻结活动时钟及动画；暂停期间不能入包、贴片、呼救或交接。重玩清空本轮状态。
- 贴片支持真实鼠标/触摸拖放、点击拿起后点落位，以及键盘Enter操作。错位/落在外面可纠正，已贴好的不重复计入。
- 分析前和建议电击前分别检查三人离开接触；不能拿分析前的清场状态自动当作电击前已确认。
- 不建议电击分支禁止电击并直接恢复帮助；建议电击后也恢复帮助，再进行交接。
- 不引入通关计时压力、患者血条或固定按压次数；时间仅用于同伴取设备的视觉交代。
- 没有AI朗读、TTS或后台音频。静音信息完整。
