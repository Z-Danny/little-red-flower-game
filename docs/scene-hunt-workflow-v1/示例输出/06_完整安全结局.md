# 06_完整安全结局

编辑目标：图1 approved-unsafe.png。生成同一房间“完成规范准备后”的整幅效果图，不生成单个物件贴图。
保持：
1. 房间视角与构图
2. 墙面、地板、阳台栏杆、窗洞结构
3. 沙发、茶几和高柜的位置尺度
4. 纸纹、水粉笔触和主要配色
只改变以下状态：
1. 阳台花盆：原花盆移到室内高柜旁的稳定地面，不挡通道
2. 敞开的窗门：同一扇门关闭并锁好，室内不再飘雨
3. 伸出的晾衣杆：晾衣杆收回，衣物收入室内
4. 闲置插线板：墙上插座空置，插头拔出，插线板盘好放在沙发侧边，不在脚下
5. 敞开的柜门：原柜门闭合，高柜上侧可见合理且不突兀的防倾倒固定带
人物结局：保持同一母子、脸型、发型、衣服和体型，坐到原有左侧沙发上，神情放松；脚下无电器
环境结局：窗外仍阴云有雨但较弱；室内色调更温暖，不变成晴天，也不表现为整理房间控制了天气
保证人物身份、家具尺度和空间关系延续原图。安全状态不能只靠加盾牌或绿色对勾表示，必须能在图上看见具体变化。
逻辑画布 720×1280，竖屏；记录真实输出像素尺寸。后续派生图须与已批准原图完全同尺寸、同取景。
只输出一张图，不要文字、标签、UI、红圈、箭头、水印、边框、拼贴展示板或棋盘格。
