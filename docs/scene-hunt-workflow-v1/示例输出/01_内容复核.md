# 01_内容复核

你负责应急科普内容审核，不负责生图。关卡：《台风前的家》。
前提：识别台风来临前未完成的准备，不让儿童在猛烈风雨或潮湿环境中实际处置电器。红圈只表示识别，不代表现实隐患已经解除。
目标清单：
1. 阳台花盆；风险：边缘物品可能被大风吹落；知识：应在台风来临前提前收回阳台易坠落物品；结局：原花盆移到室内高柜旁的稳定地面，不挡通道
2. 敞开的窗门；风险：未关闭门窗导致风雨进入；知识：台风来临前关好门窗；结局：同一扇门关闭并锁好，室内不再飘雨
3. 伸出的晾衣杆；风险：外伸的晾晒物尚未收妥；知识：提前收好阳台晾晒物和可收回的晾衣杆；结局：晾衣杆收回，衣物收入室内
4. 闲置插线板；风险：不必要电源没有提前断开，且应避免受潮；知识：事前在手和环境干燥、安全时断开不必要电源；结局：墙上插座空置，插头拔出，插线板盘好放在沙发侧边，不在脚下
5. 敞开的柜门；风险：柜门未收妥，高柜也应提前检查固定；知识：关好柜门，并提前固定容易倾倒的高柜；结局：原柜门闭合，高柜上侧可见合理且不突兀的防倾倒固定带
