# 02_完整含隐患场景

任务：为《台风前的家》生成原创完整找隐患游戏场景。不是空背景，不是物件素材表。
输入图片角色必须写清楚：风格参考图仅用于纸纹、笔触、色彩，不是需要直接复刻的房间；approved-unsafe.png 是后续蒙版、补空和安全状态编辑的唯一构图母版。
构图：手机竖屏，正面看向阳台，视点位于客厅内；单一连贯空间，透视自然。空间：现代中国家庭客厅连接阳台。家具：左侧青绿色沙发，右侧暖木高柜，右下圆角茶几；中央留有人物站立空间，窗外可见城市与栏杆。
视觉风格和材质：暖色纸纹绘本风二维室内插画；奶油米色墙面、低饱和青绿色门窗和沙发、蜂蜜色木地板，水粉笔触、柔和纸张颗粒、统一柔光和自然接触阴影。
人物：母亲穿奶油色上衣与棕色长裤，孩子穿青绿色上衣与米色长裤，抱着小熊；两人站在中右部，紧张地看向阳台，不遮住五个目标
环境：窗外阴云、大风和斜雨；室内没有大面积积水，人物脸上没有雨滴或汗滴
把以下 5 个目标直接画进同一房间，透视、照明、笔触、接触阴影一致，每个恰好一处：
1. plant / 阳台花盆：一盆红花连同陶土花盆放在窄栏杆边沿；位置：阳台栏杆上缘、中上偏右。
2. window / 敞开的窗门：一扇向室内打开的青绿色玻璃窗门，有明确门框和玻璃轮廓；位置：阳台左侧。
3. rail / 伸出的晾衣杆：一组向外伸出的金属晾衣架，挂着一件奶油色上衣；位置：阳台左上部。
4. powerstrip / 闲置插线板：一个接通但当前不必使用的浅色插线板和插入的充电器，电线连到墙上插座；位置：沙发附近地毯左下部。
5. cabinet / 敞开的柜门：高柜上部有一扇敞开的木柜门，下方普通抽屉是关闭的；位置：房间右侧高柜。
物理关系：
1. 插座只能装在真实墙面上，不能在沙发布面上
2. 插线板电线有连续合理的来路
3. 柜门可与下方普通抽屉区分
4. 只出现一个目标花盆、一个目标插线板；无多余雨伞
5. 目标不得被人物、家具或界面遮得无法识别
顶部约 8% 只放非关键细节；底部约 12% 不放唯一识别特征。具体可点性须按真实手机 UI 再检查，不能只相信百分比。保持场景自然丰富，不用装饰堆砌遮住目标。
逻辑画布 720×1280，竖屏；记录真实输出像素尺寸。后续派生图须与已批准原图完全同尺寸、同取景。
只输出一张图，不要文字、标签、UI、红圈、箭头、水印、边框、拼贴展示板或棋盘格。
