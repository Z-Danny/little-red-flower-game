# 04_同构ID蒙版

输入图1：approved-unsafe.png，精确分割母版，不是风格参考。
输出与图1同像素尺寸、同构图、逐物件对齐的平涂 ID 蒙版。不重画物体形状，不移动、旋转、缩放或补出被遮挡部分。纯黑 RGB(0,0,0) 表示所有背景和未列物品。
各 ID 的颜色、包含/排除边界如下：
1. plant / 阳台花盆，位置 阳台栏杆上缘、中上偏右，纯色 RGB(255,0,0)。包含：花盆、红花和枝叶的可见外轮廓。排除：栏杆、窗外树木、阴影。
2. window / 敞开的窗门，位置 阳台左侧，纯色 RGB(0,255,0)。包含：敞开左侧门扇的门框和玻璃，不是整个阳台开口。排除：右侧整个室外区域、墙、窗帘。
3. rail / 伸出的晾衣杆，位置 阳台左上部，纯色 RGB(0,0,255)。包含：伸缩架及其奶油色上衣的可见轮廓。排除：背景、开窗框、窗外天空。
4. powerstrip / 闲置插线板，位置 沙发附近地毯左下部，纯色 RGB(255,255,0)。包含：插线板本体和插入的充电器。排除：长电线、墙面插座、地毯。
5. cabinet / 敞开的柜门，位置 房间右侧高柜，纯色 RGB(255,0,255)。包含：敞开木柜门的可见门扇，不是整个柜体。排除：下方普通抽屉、墙面、柜内物品。
纯白 RGB(255,255,255)：母亲穿奶油色上衣与棕色长裤，孩子穿青绿色上衣与米色长裤，抱着小熊；两人站在中右部，紧张地看向阳台，不遮住五个目标 中人物及随身物品的可见轮廓，仅供人物提取，不是隐患。不要包含投影、背景空隙或邻近物件。
颜色必须实心纯色，无渐变、纹理、透明棋盘、文字、描边、抗锯齿彩边。保留对象真实遮挡关系，不能以包围矩形代替轮廓。输出蒙版一张。AI 结果仅为候选，必须交由程序量化和人工叠加复核后才能用于点击。
