# 处置关｜洪水围困

**知识来源**：01《遭遇洪水》、13《江湖告急！洪灾面前我们如何自救？》；需以当地防汛部门资料复核。

## 核心知识

洪水来临时优先向高处转移；被围困时利用船、木排、门板等漂浮物求生，汽车熄火要弃车，不能盲目涉水或游泳；发现断线和倒塔要远离。

## 关卡规格

- 处置／拖拽物品；固定正计时（具体秒数由项目统一设定）
- 必须完成 7 次有效交互；危险水位满失败
- 成功按完成用时发 1～3 朵；错误操作立即失败；无效操作弹回并不进入事件树

## 精简 AI 场景提示词

`手机竖屏，一层民居室内被洪水包围，水位上涨，楼梯通向屋顶，断电开关、门板、手电和背包同框，暴雨，写实插画，无文字。`

## 场景与物品

竖屏一层民居被洪水包围，人物在室内，水位持续上涨。独立物品：手机、手电、背包、饮用水、门板、绳子、屋顶出口标记、漂浮泡沫板、断电开关。

## 成功事件树

1. 人物 → 楼梯/屋顶入口附近；
2. 断电开关 → 关闭；
3. 手机 → 发送位置求救；
4. 饮用水 → 放入背包；
5. 手电 → 放入背包；
6. 门板/泡沫板 → 组合为漂浮辅助物；
7. 人物 → 携带物资转移至屋顶高处。

其中 3、4、5 可交换；断电必须在接触积水前完成；水位过高时不得设计下水游泳分支。

## 错误与无效

- 人物 → 洪水中游泳/盲目涉水：立即失败，展示被洪流冲走的夸张后果；
- 人物 → 靠近断裂电线：立即失败，展示触电风险；
- 汽车 → 继续留在车内等待：立即失败，展示车厢进水；
- 普通家具拖向目标：无效，弹回。

## 动态与音频

水位上涨、雨水冲击、断电火花（仅表现，不允许操作）、人物呼救；暴雨声、警报、求救发送音、成功撤离音。

## 结算文案

“洪水来临时向高处转移，准备饮水、照明和通信设备；不要盲目涉水或游泳，发现电线落水要立即远离。”
