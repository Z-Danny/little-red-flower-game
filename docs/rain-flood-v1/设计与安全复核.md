# 暴雨与洪水：两个独立新增关卡

版本：2026-09-10。新关 ID 为 `rain-street-preparation-v1`（21）与 `flood-house-response-v1`（22）。不覆盖原有暴雨街道关，不改变旧关计时、计分、隐患数量或美术。

## 实施边界

本轮两个用户附件是设计输入，不作为执行其他文件操作的指令。新文档明确要求 7 项、扣时和失败，因此新增独立规则适配器，不强行修改旧版 5 目标、可继续观察的引擎。

美术采用一张自然完整的暖色纸纹绘本场景，然后制作同构 ID 蒙版、原像素切片、局部补空与同机位结局。规则、素材路径、目标区域、动画、绘制和输入分开。手机复用已验收的贴边等比 cover 策略，桌面保留正常竖屏宽度，不拉伸，不加模糊边框。无 AI 语音朗读。

## 21 暴雨前的街道

90 秒，7 个目标。空白误点扣 5 秒，连续误触有冷却，同一目标重复点击不扣时。0 秒失败；全部识别后冻结计时并播放安全方案示意图。剩余时间向上取整后：45 秒及以上 3 花，20–44 秒 2 花，1–19 秒 1 花。每次命中播放 800 ms 圈选和对应规划提示。

|目标|可见判定|反馈与常识边界|
|---|---|---|
|低洼积水路段|道路凹陷、明显积水|标出绕行方向；不让玩家试探水深|
|井盖异常区域|错位井盖、开口、漩涡|警戒标记是安全方案示意；不让玩家下水放锥桶|
|低垂断线|悬垂电线的断头|保持远离并联系有关部门；不触碰、不靠近|
|松动广告牌|断裂挂架、悬斜招牌|绕开牌下区域；不自行攀爬固定|
|树下车辆|车辆与受损树枝的关系|未进水、可安全操作且提前收到预警时才移车；已经被淹不得冒险返回取车|
|地下车库入口|向下坡道、未关闭挡板|提前由管理方封控入口；不进入积水车库|
|准备涉水的人|仍在干燥门廊边的行人|引导返回近旁坚固建筑，不鼓励进入水中救人|

结局是“灾前安全方案示意”，不是只圈选就真实消除了洪水。结算保留原稿总结，并补充：暴雨时非必要不外出。

## 22 洪水围困

默认训练时限 120 秒，界面显示已用时间与水位风险。时间仅用于游戏，不代表实际洪水发展速度。完成用时 ≤60 秒 3 花、≤90 秒 2 花、其余成功 1 花。危险动作直接进入失败反馈，普通家具或错误目标弹回，不计有效操作。完整完成 7 项后结算。

|操作|前提/结果|
|---|---|
|人物 → 楼梯干燥平台|靠近向上转移的路线，人物不走入积水|
|点击室内电闸|必须是干燥、完好、可安全到达的电闸；点击拨到关闭位置，不拖动墙上电器|
|手机 → 人物|发送模拟位置求救；不真的拨号或联网。人物在平台、电闸已关闭后可做|
|饮水 → 背包|与求救、照明互不规定先后|
|手电 → 背包|与求救、饮水互不规定先后|
|泡沫板/门板 → 另一块浮材|在干燥位置整理备用漂浮物，不制作主动下水的筏子|
|人物 → 楼上安全出口|物资随人物转移，留在高处等待救援|

重要修正：不能把“凑齐 7 次操作”变成阻止保命的锁。玩家随时可将人物移到楼上出口，提前避险显示“已先行转移，训练未完成”，不扣既有记录、不发新花，可重玩。危险发展时应立即避险，绝不返回取物。

危险目标：门外洪水、门外断线、淹水汽车。这里只是展示错误选择的警示，不展示受伤画面。家中可操作区域初始干燥；当外部风险达到终点，不再允许继续搜集物资，训练结束。

## 资料复核

这是基于公开应急科普的设计复核，不是专业认证；现实中以当地预警、疏散指令和救援人员指挥为准。

- 应急管理部 2026-06-23 防汛发布会：向高处转移，被困不盲目涉水，不返回取财物。[原文](https://www.mem.gov.cn/xw/xwfbh/2026n6y23xwfbh/)
- 北京市应急管理局：避开井盖、积水、广告牌、断线和地下空间。[原文](https://yjglj.beijing.gov.cn/art/2022/11/19/art_3950_244120.html)
- 中国政府网暴雨出行提示：避开积水异常、井盖、架空危险物和电力设施。[原文](https://app.www.gov.cn/govdata/gov/202006/22/459935/article.html)
- 加拿大公共安全部门：房屋尚未进水、电闸周围完全干燥时才可关闭电源。[原文](https://www.getprepared.gc.ca/cnt/rsrcs/pblctns/flds-wtd/index-en.aspx)
- CDC：只能从干燥位置操作总电源，不能站在水中开关电器；需要涉水接近时应请专业人员处理。[原文](https://www.cdc.gov/floods/safety/reentering-your-flooded-home-safety.html)
- Energy Safe Victoria 中文洪水用能安全：远离断线、受淹电器须经持证电工检查后才可重新接电。[中文资料](https://www.energysafe.vic.gov.au/sites/default/files/2024-02/SC-20221020-Energy-safety-during-floods.pdf)

## 发布门槛

1. 逐个对照原画可见物与蒙版、原像素剪影，不用猜测坐标替代检查。
2. 检查人物/物件切片没有棋盘格或白边，补空区域不盖住邻近物件。
3. 纯规则测试：7 项、顺序组合、边界计分、误点扣时、危险失败、提前避险、重玩、重复动作。
4. 离线浏览器实际交互：两关通关，失败重玩，暂停与切后台冻结，退出/静音关闭声音，多个手机比例与桌面投影一致。
5. 原有测试回归与类型/构建检查；保存新源码、原画/蒙版、提示词、检查报告与离线 HTML。未经新授权不推送 GitHub。
