## 已实现

- 厨房改为整屏游戏场景。常驻 HUD 只有关卡编号/名称、风险倒计时、返回、暂停。
- 移除三项正确步骤、顶部头像与表情解释、场景中的旋钮和目标名牌、重复动作字幕、底部说明区域，以及重复开场卡片。

- 逻辑世界 720×1440；`camera.ts` 同时服务绘制与反向命中，避免铺满后点击错位。正常竖屏填满；极端比例优先保护交互区域，不强拉图。
