# 红人榜与我的进度

地图右上角小红花打开同一个手绘档案弹窗，每次默认“我的进度”。红人榜与查看其他玩家是这个弹窗内的视图，地图保持挂载，关闭后保留原来的位置。

## 界面与交互

- 木框、红色标题绶带、奶油纸面，深绿金边统计木牌；文字与数值均是可访问 DOM，不烘焙在图内。
- 新头像为压低墨镜、挑眉歪笑的小红花。点击短暂歪头并显示“我先得意一下。”
- 自然灾害、公共安全、居家校园办公分别使用独立岛屿；灰色图层上按真实通关比例显示彩色区域。数值标签显示完成数/总关卡数，0 和全通关状态明确处理。
- 点击岛屿时吊牌轻摆，提示还差几关。不会跳关、领奖或改变存档。
- 两个页签支持点击、左右方向键及 Home/End。木框首尾及页签固定，中间内容独立滚动。纸牌进入 320ms，面板切换 240ms，退出 160ms（220ms 超时兜底），减少动态效果时取消动作。
- 无返回和关闭按钮；点击弹窗外部或按 Escape 关闭。关闭动作有防重复保护，保存期间防止切换视图或关闭。
- 音效共用 `RewardSound`：打开/查看、切换/轻触、关闭、确认分别调用已有短音；弹窗内部关闭全局捕获音，避免叠响，沿用声音设置。

## 数据边界

`app/game/journey/journal.ts` 只建立展示数据。当前玩家花数来自已有榜单，进度来自真实 completed，旧版 1/2 朵成绩保留。

示例阿花、隔壁老王、小林、阿圆明确标记“示例”。它们不写入存档，也不能切换为活跃玩家或获得奖励。示例与真实玩家按花数排序，同分并列，0 朵不排名。示例不是联网数据。

`BoardSnapshot.progressByPlayer` 提供每个真实玩家的独立进度副本。查看任何玩家不会调用 `switchPlayer`。只有真实玩家详情中的“使用此玩家”会明确切换，新增玩家也以“添加并使用”说明结果。修改昵称保留已有地区，切换/新建成功清除旧玩家地图定位。

种花演出期间暂禁用档案入口，避免切换玩家打断奖励演出。关卡规则、ID、奖励边界不由这个组件修改。

## 素材与校验

- 素材：`public/ui/painted-journal-v1/`；来源和生成提示：`art-source/painted-journal-v1/`。
- `scripts/prepare-painted-journal-art.mjs` 只做切片、缩放和格式编码。图像使用真实透明通道，文字留白，三岛原图全彩。
- `node scripts/test-journal.mjs`：独立只读副本、示例隔离、ID 冲突、旧成绩、同分及零分。
- `pnpm test:leaderboard`、`pnpm test:journey`、`pnpm test:journey-music`：存档、闯关和声音边界回归。
- `scripts/test-painted-journal-browser.mjs`：最终导出 HTML 的隔离、静音浏览器验收，含三种进度、三种尺寸、点击/键盘/触摸、其他玩家只读、玩家管理、减少动态效果、单次音效与静音、真实关卡启动。
- 真机及人耳试听：`not_run`；自动音频检查验证播放、静音与释放，不代表真实扬声器听感。

离线导出器显式载入 `app/painted-journal.css`，素材使用完整路径以随 HTML 内嵌。
