# 从火焰效果复用到地图环境演出

## 火焰为什么有效

原火焰不是简单的“图标在晃动”。制作时先用内置 image_gen 生成一张独立透明的水彩火焰，再用两层大小不同、相位错开的图片进行轻微缩放和倾斜，叠加动态烟雾、余烬和暖色光。火源底部固定在地图房屋窗边，避免漂移。

图片提示词要求：金黄色核心、琥珀色外沿、柔软半透明边缘、形态不对称、不画成一排相同火苗、无背景无徽章无文字，在约 80px 下仍可辨认。原始提示词保存在 `public/levels/journey-map/signals/FIRE-PROMPT.md`；图片是同目录的 `painterly-fire-v2.png`。这一版保留该火焰素材与原运动方式。

原来的其他效果主要依赖规则折线、椭圆和重复曲线，因此缺少手绘质感。现在复用火焰的做法，让图片提供质感和主体形态，代码负责位置、路径、相位、透明度和场景状态。

## 可重复的制作步骤

1. **明确现象和锚点**：先看地图实际建筑，确定故障点、水面或出风方向。效果与关卡 ID 绑定，不改玩法规则。
2. **生成透明主素材**：水彩/水粉、真实透光边缘、独立效果、无场景无底板，预留边距。每类素材单独生成，便于替换和复用。
3. **检查 alpha 和小尺寸表现**：确认有透明像素；在真实地图上检查边缘、明暗、比例和辨识度，不能只看生成大图。
4. **设置运动方案**：通常 2–3 层，分别设置路径、相位、尺寸、透明度；固定源点的电火花不应整团飞走。
5. **配置场景坐标与触发区**：`anchor` 对齐效果源点，`hitArea` 对齐建筑/街道。更换地图构图时单独调整这两个配置。
6. **验证状态切换**：悬停增强、移开恢复；已种花仅作临时情景回顾；种花过程中隐藏演出，奖励和存档不受影响。
7. **交付最终离线包**：将图片内嵌到 HTML，再对该文件做浏览器验证，并校验同步后 SHA。单张素材成功生成不代表接入完成。

## 运动配置示例

`content/journey-motion.json` 中，素材和运动方案分别维护：

```json
{
  "asset": "wind",
  "size": [150, 85],
  "path": [[37,151], [120,152], [144,88], [73,55]],
  "seconds": 4.8,
  "copies": 2,
  "phase": 0.3,
  "scale": [0.7, 1.02],
  "rotate": [-18, 20],
  "opacity": [0, 0.62, 0]
}
```

- `path`：依次为起点、两个控制点、终点。点位处于 160×200 的效果局部坐标。
- `size`：素材框尺寸；保留图片自身比例。
- `seconds`：完整一次运动的时长。
- `copies`：同路径错开时间的层数；`phase` 为初始相位偏移秒数。
- `scale/rotate`：起止缩放与旋转角度。
- `opacity`：开始、主体阶段和结束透明度。

纯计算模块把曲线采样为 9 个位置，再由 CSS 插值执行。运行时没有每帧 JavaScript 定时器，也不依赖 SMIL。屏外、隐藏页面会暂停；“减少动态效果”固定在中间位置，仍显示素材。

不要把所有素材设成同一条往返路径，也不要统一放大成盖住房屋的贴纸。雨应下落、蒸汽应上升、水应贴地流动，光影应克制。


## 颜色与可见度

非火焰素材有独立 `appearance` 配置：`alpha` 加强原图透明度，`saturation` 控制饱和度，`brightness/contrast` 控制亮度与明暗对比，`edge` 设置柔和边缘阴影颜色。风和蒸汽稍微压暗亮部以便从浅色地图中分离，水保留蓝绿色，电花保留明亮蓝白色。图像文件不修改，效果仅作用于通用素材层，原火焰不经过此调色。

未悬停预览的 `restOpacity` 为 0.32；悬停整体为 1，主层透明度峰值为 0.82–0.95（灯光、水面单独降低）。原有淡入淡出与路径保留。颜色强度、单层透明度和整组透明度是不同层级，调整时需看最终地图效果。
