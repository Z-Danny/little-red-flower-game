# 首页与地图的统一画面尺寸

2026-09-13

## 本次修复

左上标题成为返回首页按钮后，继承了工具栏图标按钮的 44px 固定宽度和居中规则，文字从狭窄按钮向两侧溢出。现在标题组有独立的弹性宽度、左对齐与必要时换行规则，右侧工具保持 44px 点击区域；不隐藏或省略标题文本。

首页此前占满窗口，地图最大宽度为 520px。在 704×828 的复现窗口中，首页宽 704px、地图宽 520px，切换会突然变窄。现在两页共用 app/journey-frame.css 的 --journey-frame-max-width，最大宽度 520px，高度 100dvh，统一居中与外侧底色。移除首页单独的桌面双列布局，使桌面也保持同一竖屏画面。

修改最大画面宽度时只需修改共享变量；app/title-screen.css 负责首页内部排版，app/garden.css 负责地图内部排版。离线导出器同步内嵌共享样式。

## 验证

scripts/test-entry-layout-browser.mjs 在隔离静音浏览器中检查 320×568、390×844、520×830、540×830、704×828、1440×900：两页 x/y/宽/高一致，三张地图的完整文字边界位于标题按钮和画面内，不与右侧按钮重叠，顶部点击区域不小于 44px。

35 朵花为专用布局测试夹具；检查导航与刷新前后存档字节不变，不声称在本次布局测试中真实获得这些奖励。首页专项测试另行覆盖旧存档、玩家切换、继续定位。未改关卡规则、奖励逻辑或图片。真实手机未测。

最终离线文件 SHA、截图和结果见 entry-layout-verification/report.json；baseline 子目录是修复前复现记录。
