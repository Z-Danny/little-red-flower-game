# 角落工具与扇形地图切换（历史版本）

当前地图切换已经改为[天空群岛选择页](MAP-ARCHIPELAGO.md)。四分之一圆入口保留，扇形展开行为已移除；以下保留历史设计和验收记录。

按 2026-09-15 的新布局要求，移除地图顶部横栏，改用右上角竖排工具和左下角四分之一圆地图切换。三张地图的关卡规则、存档、坐标和解锁关系沿用现有实现。

## 布局与操作

- 右上角：三个 56 × 56px 按钮竖排，依次为黄色首页小屋、红花数量、花匠调节匣设置，比前版 64 × 64px 缩小。随游戏画面固定，适配安全区。使用已确认的透明底绘本图片，直接放在地图上，没有底牌或额外按钮背景。首页与设置没有可见文字；实际累计花数显示在空白花芯中央，点击进入守护档案。独立成就奖杯入口移除，声音开关和重置记录移至游戏设置。素材与计数实现见 [MAP-CORNER-STORYBOOK.md](MAP-CORNER-STORYBOOK.md)。
- 左下角：112px 半径的四分之一圆按钮显示当前地图图标和名称，点击展开为 236px 半径的扇形菜单。
- 三个选项沿外弧排列；当前地图用浅绿色底色标记。选择不同地图后定位到该地图的可用节点，随后收起；选择当前地图只收起菜单，保留滚动位置。
- 再次点击主按钮、点击菜单外侧或按 Escape 收起；菜单支持 Tab、Enter 和空格键。键盘收起后焦点回到主按钮。
- 种花演出期间停用地图切换，沿用原有演出和奖励流程。
- 地图铺满游戏区域。收起时左下角仅保留小扇形；展开时通过透明遮罩避免误触下方关卡。

- `scripts/test-map-fan-browser.mjs`：针对最终离线 HTML 的浏览器验收；早期轮盘测试保留为历史记录。

## 导出与验证

```sh
node scripts/export-offline.mjs
node scripts/test-map-fan-browser.mjs
```

本轮交付使用默认导出的 `outputs/本地离线版/小红花应急行动.html`。浏览器验收读取这个最终文件，以隔离存储、静音方式执行，并在 `finally` 中关闭浏览器。新存档与 63 花测试存档分别检查；测试存档不代表真实通关。

历史扇形地图验收位于 `outputs/map-fan-verification/`，摘要为 `map-fan-verification.json`。本轮透明图标、设置入口及缩小布局已在最终 `outputs/地图透明图标版/小红花应急行动.html` 中通过验证，报告为 `outputs/map-corner-garden-verification/report.json`，包含三类地图切换与存档保持检查。真机触控和人耳听音：`not_run`。
