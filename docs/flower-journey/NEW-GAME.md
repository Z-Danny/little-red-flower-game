# 开始新游戏

2026-09-15 更新：当前首页按存档显示“开始游戏 / 继续游戏 / 重新开始”，首次或零成绩重开不调用成绩重置，有通关成绩才确认清空。继续位置校验和跨标签书签同步也已更新。当前规则与验证入口见 [分层动态封面](../animated-cover/README.md)；以下保留最初重开功能的历史记录。

2026-09-13

首页“开始游戏”更正为“开始新游戏”，不再只是跳到地图。已有花朵或地图探索书签时，浏览器确认框明确说明将清空当前玩家的小红花、关卡完成记录和解锁进度，保留昵称、地区及其他玩家记录；取消不写入任何数据。没有记录的首次玩家直接开始。

确认后等待存档服务的重置结果，成功才关闭首页、清理当前关内会话和待结算状态、重置种花演出状态，将当前玩家地图书签移到自然灾害的起点。解锁状态继续由清空后的完成记录推导，不单独篡改节点。存档操作失败时留在首页展示错误，可重试。

“继续游戏”保持原功能，恢复地图节点和已有成绩，不重置。重开后重新通关可再获该新进度中的首次奖励；同一进度重复通关不重复领花。

## 修改入口

- content/journey-home.json：按钮名和确认文案。
- components/game/game-app.tsx：新游戏事务和会话清理；使用防重复执行标记。
- components/game/journey/title-screen.tsx：忙碌时禁用开始、继续、玩家切换入口，展示重置错误。
- components/game/leaderboard/use-leaderboard.ts：重置返回可等待的成功/失败结果。
- app/game/leaderboard/local-provider.ts：重置前核对已确认的玩家 ID；如果另一页面刚切换玩家则拒绝操作，避免清错他人记录。
- app/game/leaderboard/model.ts：存档接口允许传入已确认的玩家 ID。

地图书签仍独立存放，以当前玩家 ID 覆写为起点，其他玩家书签保留。未改任何关卡内容、艺术素材、奖励数值、判定或地图分类。

## 验证

44 项 journey/相关规则测试通过，包括重置后锁定、玩家隔离、跨页面玩家切换保护、重新领取首次奖励和防止重复领奖。TypeScript 和生产构建通过。改动文件 lint 检查中 use-leaderboard.ts 原先已有的三条 Hook/React compiler 诊断仍存在，已与维护源码基线对比，本次没有新增该类诊断。model.ts 的资料过滤正则另有一条基线已存在的 no-control-regex 诊断，未更改该过滤逻辑。
