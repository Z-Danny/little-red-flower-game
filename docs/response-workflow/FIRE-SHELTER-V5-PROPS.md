# 高楼火灾道具修订 V5

取代 V4 文档中“第二块湿布”和“点击人物求救”的描述，其余六目标及危险分支保持不变。

- 场景只保留一块湿毛巾，拖到门底缝后变为封堵状态。
- 原第二块湿布替换为独立胶带卷，拖到相同门缝加固；1100ms 演出将卷状道具切换为逐渐展开的胶带条。不新增湿毛巾残影。
- 人物仅负责拖动到安全位置，不接受点击求救。完成前五目标后，把桌上手电筒拖到母亲所在的接收区域，1300ms 接灯/举灯演出后发出直线信号。
- 接收区与可见提示共用 `family-signal`；只在人物到达室内安全位置且尚未求救时出现。错误位置放回，不跳过目标。手电筒移交后桌上的独立图层消失，光束仍绑定人物图中灯口。
- 规则只在 `level.json`；图片、位置、接收区、动画只在两份皮肤配置。本次没有改公共运行器。

## 资源和生成方式

内置 imagegen 生成，不指定模型版本。原图保存在 `art-source/shelter-props-v5`，最终透明资源为 `public/levels/shelter-props-v5/tape-roll.webp` 与 `tape-strip.webp`。

胶带卷提示词：单个宽幅灰米色哑光密封胶带卷，轻俯视三分之四视角，短端翘起，卷芯空洞清楚。暖纸纹水粉/铅笔绘本质感，低饱和、室内偏暗柔光、棕色细轮廓。完整物品、真正透明RGBA背景含卷芯，无桌面、文字、人物、背景块、棋盘格。

胶带条提示词：单段已完全压平的灰米色胶带，水平细长、约10:1、两端略撕裂、无卷曲，暖纸纹水粉/铅笔、低饱和室内柔光，单独透明RGBA，无房间、人物、文字或其他物件。

后处理 `python scripts/prepare-shelter-tape.py`：原生alpha去除低透明彩边与游离像素、保留最大主体、保留卷芯空洞、不填孔，不按白色阈值删图；等比裁切缩小并保留透明边。深绿及浅纸色底预览仅用于边缘检查，不进入离线包。

## 验收

`node scripts/test-fire-shelter.mjs` 验证单毛巾/胶带资产、人物不再tap、手电拖入才授予目标、桌上手电消失、直线光束与原六目标。

`node scripts/test-shelter-browser.mjs` 实际拖动测试两件独立道具，四种手机视口及桌面尺寸；`--main` 对实际主地图测试失败无奖、正常通关与重玩不重复奖励。报告和截图在任务工作副本的 `outputs/shelter-verification*`。真机和人耳试听未做。
