# 高楼火灾 · 本轮修订及维护入口

## 范围与事实

正式源码中的 `content/levels/fire-shelter-practice` 是唯一规则/皮肤来源。本次明确修改机制：六个目标改为关门、湿毛巾封堵、湿布加固、模拟119并报告位置、人物移至室内避险位置、人物发出信号并等待。保留关卡ID和旧存档。外伤、触电仍不进入正式地图。

移到安全位置、拨打119不被人为前置锁住，避免为了游戏顺序而暗示现实中应延迟报警。最后的求救/待援目标需要前五项均完成。封堵不保证隔绝所有毒气，房间内起火等不同情境不适用本关。

最新用户明确要求以下选择立即失败：打开房门探查、人物进入浓烟走廊、人物跳窗。`Interaction.failure` 只能配置在 `danger` 操作上；立即冻结、不发花、可重玩。其余关卡未启用此字段，仍采用原来的可恢复错误行为。普通家具拖到门缝无效。

消防知识核对：

- [国家消防救援局：高层建筑发生火灾](https://www.119.gov.cn/site1/kp/hzyf/gcjz/2022/31825.shtml)：关闭房门、封堵缝隙、119报告被困楼层房间、发出求救信号。
- [国家消防救援局：高层起火自救](https://www.119.gov.cn/kp/zjts/hz/2022/34418.shtml)：门缝有黑烟时不要开门，封堵并报警等待救援。

本关当前窗外无烟火冲击，人物留在室内、远离玻璃位置用手电示意，不要求开窗或靠近窗台。接通和到达均为离线模拟，不是现实救援时长承诺。需专业人员审核后再用于正式安全教育。

人物移到安全处后点击即可举手电求救；同一人物仍支持拖动，不复制一个重叠的新热区。两张新人物状态与旧低姿状态独立，未把人物烘焙进背景。删除的只是本关男子图层引用，原资产保留以便恢复。

门底实测约为设计坐标 `(480,580)` 至 `(608,610)`。最终毛巾和加固湿布的旋转需同时考虑原图自身斜向；不能单用画布矩形中心定位。拖动提示与判定共用 `door-gaps`，其余动作提示只在拿取相应物品时出现。

## 声音边界

专用声音ID：`fire-alarm`、`heartbeat`、`nonverbal-cough`、`telephone-connect`、`rescue-arrival`。固定种子DSP、PCM22050、去直流与首尾淡化、采样峰值<=0.72，再经总线压缩。咳嗽是无字词合成气流动作声，**不是录制真人声音，也不是TTS**。火警/心跳周期和咳嗽图由关卡活动时间驱动；暂停、隐藏页面、静音均遵循公共音频控制。完成和失败停掉背景循环，仍允许收尾提示音。

救援到达声在六项目标后的等待演出中播放一次。训练结束仍提示保持联系，不把外部火灾画成已熄灭。

## 美术生成提示词与后处理

使用内置 imagegen，不指定或声称特定模型版本。输入参考：`public/levels/character-continuity-v3/fire-shelter-practice/family-worried.webp`，身份与画风参考，不重画房间。

1. 警觉：同一珊瑚毛衣/米白长裤的母亲及芥黄上衣/蓝裤男孩，完整全身、屈膝向左退，母亲护住孩子，两人明确看向画面右侧的危险房门；暖纸水粉铅笔纹理，成人与儿童比例正确，仅两个人，无背景、文字、白边。
2. 咳嗽：同一身份与衣服，二人低姿蹲下，母亲抬起弯曲手肘遮口咳嗽并保护孩子，孩子捂嘴担忧，肢体清楚，完整脚部。请求透明通道。
3. 求救：同一母子低姿，母亲举黄色手电向左上窗外示意、另一手护孩子，警觉但略有希望，不站起或靠窗；无光束（代码绘制）、无房间、无文字。纯品红底用于抠图。

第一张透明请求返回了烘焙棋盘格，已二次调用生图只替换背景为纯品红，再去背；未把棋盘图投入游戏。咳嗽图原生透明但外围有低透明晕染，经alpha边缘清理。求救图做品红去背；不按白色阈值删除肤色或米白裤子。三个状态均在深绿/浅纸色底检查，裁切后保留4px透明边；原始输入未覆盖。

## 手电筒光学与画面校验

求救状态重新生成了向左上举灯的手腕与灯筒姿态，维持母子身份。光源锚点与灯筒轴线在皮肤 `beam` 中配置，`attached-beam.ts` 用人物当前姿态的同一个刚体变换计算灯口和四边锥形光束；不向预设窗口点折线连接、不另画窗口光斑。人物摇动时，灯口、轴线与光束一起转动。单元测试检查光束中线共线与旋转后的灯口坐标。

本轮专项浏览器检查：四种手机尺寸和桌面尺寸、实际边缘拖放、六动作成功/等待、危险动作立即失败、暂停、重玩均通过；实际主地图入口完成奖励3朵、失败无奖、重玩不重复奖励均通过。截图及浏览器报告保留在 `outputs/shelter-verification` 和 `outputs/shelter-verification-main`。

完整地图浏览器脚本另在旧台风关返回地图的种花瞬间断言失败，本轮未修改无关地图动画，不能据此声称全地图浏览器回归通过。源码全量测试、类型检查、构建与本关专项验收分开记录。未做手机真机测试或人耳试听。
