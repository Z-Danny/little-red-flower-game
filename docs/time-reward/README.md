# 按用时分档的小红花（2026-10-07）

适用正式地图全部 24 关；不改通关目标、失败条件、关卡 ID、画风、镜头或存档结构。

## 规则
- 成功通关：评分用时 ≤ 本关参考时长的 50% 得 3 朵；≤80% 得 2 朵；其余成功得 1 朵。
- 失败、未完成、提前撤离但未完成训练：0 朵，不调用领奖接口。
- 计时来自实际运行引擎（包含原有误操作扣时），不是现实墙钟。暂停、隐藏页面、加载/介绍、结局演出不计入；正常观察、操作动画、必须完成的训练等待计入。不限时训练仍允许慢慢完成，不新增失败截止时间。
- 配置/厨房引擎在结算回调中减去结局演出时长；找险与灾害引擎的 elapsed 在揭晓阶段已冻结。灾害额外加上其单独记录的 penalty。
- 每关持久化最高 1～3 朵；仅补发正差额，不扣花、不累计刷花。旧记录保持，旧低分可提升。旧 3 朵不会因新规则降分。总上限保持 72 朵。
- 精确毫秒比较，临界时长含等号。UI 向上取到 0.1 秒，避免超过阈值却显示为阈值以内。
- 入口与结算共用评分模块，不改教学内容。科普操作正确性优先于速度。
