# 4-7 绘本图像化 UI 改版

日期：2026-10-07。范围仅限 CPR 游戏的界面与指引表现，未发布。

## 视觉对应

| 原界面 | 改版 |
| --- | --- |
| 普通返回、问号、暂停方按钮 | 复用其他关卡的 `PaintedIcon`：金色返回箭头、叶片灯泡、绘本暂停 |
| 六步数字与文字流程条 | 六枚图像徽章、金色连线与完成印记，不伪装成倒计时 |
| “请你呼救”“请你取AED” | 旁人身上的电话、AED图标，带任务进行/完成小徽章 |
| “胸部一侧”“脚边”按钮 | 场景中两处跪姿定位标记，维持原坐标与判定 |
| 手位和姿势文字选项 | 两张有区别的插画式手位图卡、两张直臂/弯肘姿势图卡 |
| “跟着节奏点按”大文字按钮 | 双手图标点按区、心形节拍指示、叶片采样进度 |
| 快慢文字反馈 | 兔子（偏快）、蜗牛（偏慢）、勾（接近提示）；灯泡内保留图例和精确纠正说明 |
| 交接/完成长按钮 | AED与接力双手图示、接力与完成印记，不改变可以提前交接的规则 |
| 白色常驻大段说明 | 收入灯泡纸张帮助卡；底部仅保留“仅模拟练习 · 不评定真实CPR能力” |

没有把长说明简单栅格化成文字图片。主要操作通过图示表达；标题、必要的100—120次/分数值、安全提示及帮助/暂停文字保留可读性。每个图像按钮有完整的中文`aria-label`；过程反馈保留在屏幕阅读器状态区域。

## 素材与诚实边界

- 保持原背景、患者、施救者、接替者、AED道具不变，不修改任何场景相机和目标坐标。
- 项目原有位图：`public/ui/painted-v1`、`public/ui/pause-v1/paper.webp`，原样复用。
- 新增16个可编辑SVG素材：`public/ui/response-training-v1`。与项目已有SVG道具/图标相同的本地资产工作流，以暖金、褐色轮廓、叶片和纸张色统一；无文字嵌图、脚本、外部引用。
- 作者脚本：`scripts/author-response-training-ui.mjs`；路径清单：`app/game/response/training-art.ts`。离线导出能识别全部字面量路径。
- 尝试调用生图服务，但返回HTTP503 / model_not_found，**未生成新的AI位图**，未改用收费CLI或其他模型。新增图标是本地原创SVG，不声称是生图结果。

## 技术边界

- 继续复用处置类 `useGameViewport` / `createCoverCamera`。不新增关卡相机、手机断点或独立CSS文件；样式仍在 `app/configured.css` 的通用response-training块。
- `rules.json`、`skin.json`、`cpr-model.ts` 与改版前SHA-256一致（见`visual-contract.json`）。ID、开始帮助的可用性、12段采样、独立AED到达和提前交接都不改。
- 灯泡帮助与暂停使用既有纸张素材；打开时冻结练习时间，恢复时重置起拍；对话框支持焦点约束、Escape关闭、关闭后恢复焦点。
- 无新增TTS、声音或自动播放。未修改真实玩家存档。
