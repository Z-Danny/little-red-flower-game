# 4-7 心肺复苏实战 · 本地实现与验收

- 稳定 ID：`first-aid-cpr`，第四章第七关。独立情境处置状态机，不迁入找隐患模板，不影响七目标暴雨和洪水规则。

- 本次只做本地文件，不提交、不推送、不发布。

## 玩法设计

1. 场景已确认安全；成人突发倒地、无反应、无正常呼吸。场景说明不要求玩家重新找手机或判脉搏。
2. 点击旁人分配呼救及取AED任务。呼救使用中国大陆场景的120，帮助里说明其他地区用当地急救号码。
3. 「立即开始帮助」始终可用，不依赖呼救按钮、AED、收集品或连击。
4. 点选胸部一侧；脚边错误可恢复。点选双手示意放在胸部中央；腹部错误可恢复。选择双臂伸直、肩在手正上方；弯肘错误可恢复。
5. 正确手位和姿势后进入输入节奏练习。提示100—120次/分，光点引导110次/分；只报告快慢，不给真实深度或真实技能合格结论。12段只是本关输入采样数量，不是急救剂量、不要求连续全对。防止极快点击和长按重复刷样本；长停顿与暂停后重新起拍。
6. 分配取AED后独立推进8秒**游戏演出时间**，不表示真实取得设备所需时间。AED到达后立即允许接替，采样为零也能交接；不等连击、采样数或评分。
7. 接替后由另一位协助者继续模拟按压，玩家可完成剩余屏幕采样。结算遮罩下面仍保留持续救助；不演患者坐起、苏醒或已救活。
8. 本关采取「交接给继续帮助的人」分支，不做电极贴片、分析、电击操作。结算知识区说明听从AED提示、分析/电击时勿接触患者、之后按提示恢复CPR。

## 美术与演出

- 原创绘本水粉：米白、鼠尾草绿、暖木色和赭红，与前三张地图保持柔和绘本方向。
- 场景是平整干燥社区广场，患者仰卧在坚实地面，无枕头、床垫和多余道具；患者不随输入跳动。
- 新背景、红衣施救者、绿衣接替者均为本轮生图工具产出。AED包为可编辑SVG小道具，手位图为明确标识的代码示意图；均无外链。
- 手部锚点、患者和人脸关键区域重新按新素材标定，不借用旧关坐标。
- 人物同步效果是锚点固定的轻微形变，不是骨骼动画、不表示真实胸部位移。减少动态偏好时取消形变，保留状态与节奏提示。
- 旁人任务以标签反馈；**没有完成取AED人员离场/返回的逐帧动画**。补充离场背景的生图请求失败（503），没有伪称成功或用其他模型替代。该项属于后续美术完善。
- 本关不新增语音或TTS，也不加入急促心跳造成真实生命体征误解。新节奏引导为视觉提示；新关没有专属音乐/节拍音频，人耳试听不适用且记录为not_run。
