# 井口遇险求助：交互改进（2026-09-27）

## 本次实现
1. **劝阻而非摆放人物**：拖动旁观者到外围后显示提醒结果与他的文字回应；提示和误放反馈不再称人为“它”“物品”。保留原有拾取蒙版、拖放区域及退后动画。
2. **观察与危险动作分离**：单击井口是中性观察，不计错误、不增加恐慌、不授予目标；把人拖向井口仍触发危险警告，之后可纠正。
3. **两通独立的模拟通话**：119要求说明位置和险情；120要求如实说明已知人数和状况，不猜测伤情。点号码只接通，回答后才完成该项目标。119、120和劝退旁人的六种先后组合均可完成。
4. **现场信息可回看**：任务栏下提供现场位置、已知信息和玩家/旁观者身份说明。信息卡可滚动，支持窄屏。
5. **外围待援收尾**：三项任务完成后，旁观者提出靠近井口查看，需要再次劝阻才结束。本关没有强制挂机或救援倒计时。
6. **反馈位置优化**：本关的提示条移至上方，落点标签放在目标框上方；已通过几何断言确认不会覆盖119、120及外围目标区。

## 实现边界
- 复用已有 `Rules.coaching` 对话能力；新增可选的场景信息、对话小标题、规则提示与对象误放文案。
- `Skin.feedback` 只控制提示位置与目标标签位置，不改变相机、目标区域或发奖逻辑。
- 规则推进仍在引擎动画提交时发生，选项按钮不直接写目标。暂停、重复输入、未来步骤输入和重开均经过测试。
- 源码中没有新增按井口关ID分支。未启用字段的其他关卡沿用默认行为。
- 美术资产、世界尺寸、相机取景、人物初始位置/状态和目标区坐标与本轮修改前一致。
- 观察井口改用中性提示音映射；没有新增语音、TTS或朗读。
