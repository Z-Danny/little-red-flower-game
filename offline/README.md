# 小红花应急行动 · 本地离线版

## 如何打开

双击同一目录中的 `小红花应急行动.html`，使用电脑上的 Edge、Chrome 或其他现代浏览器打开。

- 无需安装 Node.js，无需启动服务器，无需登录，也不需要联网。
- 游戏脚本、样式和场景图片全部包含在 HTML 内，可以单独复制这个文件。
- 如果文件被文本编辑器打开，右键选择“打开方式”，再选择浏览器。
- 本版本保留原有 16 关，新增 8 个处置练习，共 24 关。**外伤大出血、触电：待专业审核，暂不加入实际地图。**两关仍仅在独立审阅包。旧关保留，不覆盖原台风关、原三目标《充电中的卧室》或原有街口关。
- 记录尽可能保存在当前浏览器中。某些浏览器在本地文件模式下不允许长期保存记录，但仍可正常游玩。
- 手机请先下载文件再用浏览器打开；微信等应用的文件预览不一定支持运行游戏。

## 如何游玩

首页和地图的「忙归忙，能搞定」配乐在首次点击或键盘操作后启动。切换地图时连续播放，进入关卡时淡出，返回地图时续播；切到后台会暂停。地图右上角的游戏设置中可独立开关首页／地图音乐，并记住当前浏览器的选择。按钮／奖励音效和关内声音使用各自的开关；按钮／奖励音效设置也会保存在当前浏览器。

打开游戏先进入绘本首页。“开始新游戏”会在确认后清空当前玩家的小红花、关卡完成记录和解锁进度，从自然灾害地图起点重新出发；昵称和其他玩家的数据保留，取消确认不会修改存档；“继续游戏”回到这位玩家上次探索的地图节点。首次玩家尚无探索记录时，继续按钮暂不可用。旧版花朵存档可以直接继续。关内尚未完成的操作不会保存为中途进度，刷新后继续会返回地图。

点击左下角的四分之一圆按钮，展开自然灾害、公共安全、居家校园办公三个地图选项；选择后自动收起。再次点击按钮、点击扇形外侧或按 Esc 也可收起。地图铺满画面，右上角从上到下竖排显示黄色首页小屋、红花计数和花匠调节匣，均为 56 × 56px 的透明底绘本图标，直接放在地图上。点击小屋返回首页，点击调节匣打开游戏设置；独立成就按钮已移除。初始从下方起点出发，沿路线向上探索。花苞表示可进入，灰色花苞与小锁表示尚未解锁，盛开小红花表示完成。点击节点阅读事件介绍，再进入关卡；完成后按前置关系解锁后续关卡。游戏设置中提供按钮／奖励音效、首页／地图音乐开关，以及需要确认的当前玩家记录重置。

新增 8 关：自然灾害中的地震室内避险、震动停止后的撤离、洪水围困待援；公共安全中的汽车落水离车、电梯被困求助、塌陷被困求救；居家校园办公中的隔烟与定位待援、沿可用楼梯撤离。它们使用暖色纸纹绘本美术与原交互配置，包含正确/错误反馈、阶段变化和非朗读音效。等待阶段不会被当成现实救援到达时间；待援类完成训练不代表现实已经脱险。

原存档不清除。原 16 关全通的 48 朵花保留，8 关首次全通最多新增 24 朵；新版本总计最高 72 朵。仍然是同一浏览器、同一路径的本地存档；换文件路径或换浏览器不会自动共享。

首次完成先展示安全结果，获得 3 朵小红花；点击“返回地图”后飞花、种花、增加总数并指引下一关。重玩提示“本关花朵已种下”，不重复累计；旧版 1/2 花记录保留。右上角红花的花芯显示实际累计数量，点击打开守护档案，查看累计花数、分类进度与本机排行榜；档案中不再重复提供返回首页或设置操作。

关卡 ID 与存档稳定；改地图、花朵、位置、名称和介绍请阅读源码 `docs/flower-journey/README.md`，配置集中在 `content/journey-*.json`。

### 新增 21、22：暴雨与洪水

《暴雨前的街道》：90 秒内找齐 7 个隐患，误点扣 5 秒，同一目标重复点击不扣时。顶部剪影来自原画；点击播放 0.8 秒红圈，全部完成后展示灾前安全规划示意。本轮地图首次完成固定获得 3 花，时间到则训练未完成、不领奖。结局的积水仍存在，不意味着可以涉水通行。

《洪水围困》：先把人物拖到干燥楼梯附近；点击干燥墙上的电闸关闭电源（也可先断电）。把手机拖给人物模拟发送求救位置，把饮水和手电拖入背包，把泡沫板拖到木门板处整理备用浮材，最后把人物拖到楼上安全出口。这三项求救/饮水/照明不限定先后。也支持先点击选物、再点击目标位置。

全程可以先把人物移到楼上避险：未做完训练不发新花，但绝不为了集齐物资阻止撤离。拖人物进入洪水、靠近断线或返回淹水汽车会提示危险并结束本次训练。普通椅子等无关物品弹回；点击“重新开始”可立即重玩。本轮地图首次完整通关固定获得 3 花；120 秒水位风险到顶训练结束。游戏计时不代表现实洪水发展速度。

两关都使用本地合成的雨声、风声、音乐、操作和结算音效，没有 AI 朗读。暂停、后台、静音和退出均管理音频；本机榜保留已获得的首次奖励和旧版记录，失败不清除原记录。现实中不能涉水断电，不能为取物耽误撤离，也不能靠临时浮材主动下水。

### 本机小红花排行榜

在守护档案中点击“本机排行榜”，查看排名、昵称、地区和小红花数。第一次打开会将该游戏地址原有的关卡成绩迁移到“小红花玩家”，不删除旧记录。

- “编辑资料”填写昵称和选填地区；不读取定位，请勿填写真实姓名或详细住址。
- “添加玩家”创建并切换到新的独立存档；点击其他玩家行右侧箭头可切换。
- 每关首次完成获得 3 花，旧档花数保留，重复通关不叠加；同分并列（如 1、1、3），0 朵暂不上榜。
- 守护档案中的重置按钮仅清空当前玩家成绩，不影响其他玩家。
- 这是本机榜，不是全网榜。记录保存在当前浏览器、当前游戏地址；更换浏览器、设备、端口或离线文件位置，不会自动同步。清理浏览器数据会删除存档。
- 如果浏览器拒绝存档或空间不足，会提示使用临时榜；关闭页面后临时记录可能丢失。
- 已预留联网数据接口，但当前没有联网请求、公共服务器、登录或全网反作弊。

### 找隐患

《台风前的家》：点击“进入场景”，对照顶部五个真实物件剪影寻找隐患。点击后以 0.8 秒动画描出鲜明红圈，物品不移动，红圈只表示已发现。找齐后先展示门窗关闭、物品收妥、家人坐下的完整效果图，再结算。误点不扣分，90 秒风雨增强到顶后仍能继续；暂停和切后台会暂停计时及声音。

五个隐患都在同一张绘画中，不再独立贴图。只把原画人物按蒙版提取出来做呼吸、倾身和轻颤，雨层位于人物后方，不覆盖脸部。首次点击才启用风声、雨声、背景音乐与发现/结算音效；没有 AI 朗读。暂停菜单提供静音、音乐开关和提示。练习完可返回关卡或关闭页面，避免后台持续播放。

## 源码与修改

### 本批新增：七个五目标识别关

编号 14—20 为《睡前的卧室》《开火前的厨房》《让生命通道畅通》《日常家庭防震准备》《风雨中的街口》《雷雨来临的公园》《林缘的五处火源》。物品就在完整原画中，顶部剪影从同一原画提取；点击真实物品像素，以 0.8 秒红圈标记，不移动物品。误点不扣分，但也不表示其他位置安全。

显示的是训练用时，不是现实事故倒计时。30、60、90 秒增强人物和适用环境的演出；室内预防关没有凭空出现的雨、火或烟，雨景只在室外，林缘火烟不覆盖人物。高峰仍可继续找齐。暂停、切后台会冻结时间和静音；暂停菜单可主动结束，未找齐时发放 0 朵并允许重试。找齐后先看完整结果图，再领取 3 朵；重玩保留已有记录，不刷花。

没有 AI 语音朗读。首次点击解锁本地合成音效和音乐；可在暂停菜单关闭声音。练习结束请返回地图或关闭页面。排行榜仍是本机榜，没有新加入联网数据收集。

结果图代表另一个时点：开火前厨房由专业人员完成燃气维护；街口危险仍被隔离等待处理；雷雨仍在继续，家人留在安全建筑；林缘火源由管理人员处置并检查。不能把识别完成理解为可以自行维修、靠近危险或扑火。儿童遇真实危险应立即远离并告知成人/求助。

本批源码、生成提示词、知识核对和验收索引在 `docs/hazard-batch-v2/README.md`。真机触屏、实际扬声器响度以及上线前专业内容审校需另行验收，自动测试不能代替这些检查。

### 第二关：厨房着火了

在地图选择《厨房着火了》即可进入整屏场景。直接点击灶台面板上的燃气开关，让它原位旋转关闭；把备菜台上的锅盖拖到油锅。这两项允许任意顺序，完成后把人物拖到门外安全区。也可先选物品、再点击目标；帮助、提示、音量和重玩收进暂停菜单。

厨房采用 50 秒训练节奏，左侧绘本温度计动态表示紧急程度：液柱全程统一红色，拖延或错误操作时升高，正确处置后回落；不再显示顶部时间横条或秒数。温度计不是实际温度，训练到达高危阶段仍可继续。水杯会使火焰扩大、人物惊慌后退；本关小化纤湿抹布会燃烧。餐盘、菜刀只弹回；人物右下角不再摆放灭火器。紧张音乐、燃烧环境音和无台词惊喘随局势变化，没有朗读或说话语音。人物有紧张、惊慌、专注、安心四种插画表情。本轮地图首次通关发放 3 朵小红花，重复训练保留已有记录，不重复叠加奖励。50 秒仅为游戏训练节奏，不代表现实安全处置时间。

本关小抹布无法盖严锅口，并非所有湿棉布均不适合覆盖初起油锅火。训练要求不等于现实撤离限制：现实中火势失控应立即撤离并拨打 119，儿童不要尝试灭火。

厨房模块：`app/game/kitchen/{config,model,animation,interaction}.ts`、`components/game/kitchen/`、`app/kitchen.css`、`public/levels/kitchen-v1/`。详细修改和验收见 `docs/厨房着火了_分层处置关卡说明.md`。

完整模块化源码保留在项目根目录。

- `content/scenes/typhoon-home/{rules,skin}.json`：当前台风关规则、图片、人物锚点和蒙版区域。
- `app/game/scene-hunt/`、`components/game/scene-hunt/`、`app/scene-hunt.css`：当前台风关机制、输入、渲染和音频。
- `public/levels/typhoon-scene-v3/`：当前台风关整场景与真透明人物、剪影、ID 蒙版。
- `docs/typhoon-immersion-v2/AI执行工作流.md`：当前台风关的批量制作/换皮规范。
- `content/presets/kitchen/skin.json`：当前厨房图片路径与布局。
- 以下 `app/game/typhoon/` 等是历史分层版，保留用于回归，不是当前台风入口：

## 使用边界

厨房关的火、烟、热感、人物动作及音乐随压力变化。点击右上角声音按钮或首次操作后启用声音；暂停菜单可分别调节音乐、环境、交互和人物动作音量。没有 AI 朗读或文字语音播报，呼吸/脚步等均为非语言声音。浏览器切到后台、暂停或静音时停止输出；离线 HTML 已内嵌声音，无需联网下载。

本次处置关工作流和完整提示词位于源码 `docs/response-workflow/`。新火灾类处置模板继承公共声画配置，但创建草稿不等于完成新场景或人工审核。

新增关卡与换画风请阅读源码中的 `docs/模块化关卡制作手册.md` 和 `docs/hazard-batch-v2/README.md`。通用引擎模板默认保持草稿，不计入本版可玩关卡；生成模板不等于完成主题内容和美术审核。

新增四关的物品直接位于场景中，防范关点击物品，处置关点击报警按钮、拖动人物；也可先点人物再点出现的目标区。暂停菜单提供提示与重玩。新关显示训练用时，没有灾害或救援倒计时；等待不会扣花。错误可改正，首次完成奖励纳入本机榜，重复通关不累计刷花。

应急包仅演示五类物资，不是完整家庭清单，也不能为整理物品拖延紧急转移。楼道关是没有火灾的日常整理。电梯关仅模拟普通故障停梯。井口关仅模拟没有专业防护的旁观者求助，电话不会真实拨出。两种待援场景结算时危险尚未解除。

本版有规则、动画、输入和离线自包含检查。详细结果与实际试玩范围以源码中的最新验收记录为准；本地 HTTP 试玩不等于已经在所有浏览器、实体手机或 file:// 模式逐一验收。

游戏用于应急科普练习，不能替代专业救援。公开商用前仍需自行完成内容安全、无障碍、真实设备与素材合规验收。
