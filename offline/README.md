# 小红花应急行动 · 本地离线版

## 如何打开

双击同一目录中的 `小红花应急行动.html`，使用电脑上的 Edge、Chrome 或其他现代浏览器打开。

- 无需安装 Node.js，无需启动服务器，无需登录，也不需要联网。
- 游戏脚本、样式和场景图片全部包含在 HTML 内，可以单独复制这个文件。
- 如果文件被文本编辑器打开，右键选择“打开方式”，再选择浏览器。
- 本版本包含《台风前的家》和《厨房着火了》两关；其余四关尚未开放。
- 记录尽可能保存在当前浏览器中。某些浏览器在本地文件模式下不允许长期保存记录，但仍可正常游玩。
- 手机请先下载文件再用浏览器打开；微信等应用的文件预览不一定支持运行游戏。

## 如何游玩

点击“开始关卡”及“开始找隐患”，对照顶部真实物件剪影寻找五种隐患。点击物件观看 0.75～1.25 秒的处理动画；插线板需要先点击沙发坐垫。点击顶部目标或底部“提示”可获得帮助。误点不扣分，风险达到峰值后仍可继续完成。切到后台时暂停风险计时。

本版采用原生透明 PNG 分层，不再用整张安全图的矩形裁块覆盖场景。按最新反馈已移除雨伞；晾衣杆向室内移动后淡出；插头初始插入墙面插座，拔出时金属脚露出。插线板状态灯在本关用绿色表示接通、红色表示断开，界面同时提供文字说明。坐垫拿开后消失，插线板断电后收到侧边。最后一个动作结束后，先展示家人坐下与室内变暖，再结算。

## 源码与修改

### 第二关：厨房着火了

在地图选择《厨房着火了》即可进入整屏场景。直接点击灶台面板上的燃气开关，让它原位旋转关闭；把备菜台上的锅盖拖到油锅。这两项允许任意顺序，完成后把人物拖到门外安全区。也可先选物品、再点击目标；帮助、提示、音量和重玩收进暂停菜单。

水杯会使火焰扩大、人物惊慌后退；本关小化纤湿抹布会燃烧；灭火器喷错位置会显示偏移喷射。餐盘、菜刀只弹回。错误不会造成死局；风险到顶仍可继续。人物有紧张、惊慌、专注、安心四种真实插画表情。通关发放 2～3 朵小红花，重复训练保留历史最好记录，不重复叠加奖励。

本关小抹布无法盖严锅口，并非所有湿棉布均不适合覆盖初起油锅火。训练要求不等于现实撤离限制：现实中火势失控应立即撤离并拨打 119，儿童不要尝试灭火。

厨房模块：`app/game/kitchen/{config,model,animation,interaction}.ts`、`components/game/kitchen/`、`app/kitchen.css`、`public/levels/kitchen-v1/`。详细修改和验收见 `docs/厨房着火了_分层处置关卡说明.md`。

完整模块化源码保留在项目根目录。

- `content/presets/typhoon/skin.json`、`content/presets/kitchen/skin.json`：原两关图片路径与布局。
- `app/game/typhoon/config.ts`：目标、时长、文案与风险配置；从 JSON 引入皮肤。
- `app/game/typhoon/model.ts`：独立玩法状态机，负责前置条件、计时、完成和结算。
- `app/game/typhoon/animation.ts`：物件动作轨迹与前后层级。
- `components/game/typhoon/canvas-renderer.ts`：绘制、透明轮廓点击判定、天气效果。
- `components/game/typhoon/typhoon-player.tsx`：游戏界面、音效与结果展示。
- `app/typhoon.css`：界面样式。
- `public/levels/typhoon-v2/`：原创背景与真实透明物件。
- `scripts/export-offline.mjs`：独立离线 HTML 导出工具。
- `docs/台风前的家_二维重制说明.md`：模块接口、修改方法和验收说明。

修改源码后，在项目目录安装已有依赖并运行 `pnpm run export:offline`，即可重新生成离线文件。导出仅读取本地素材，不连接外部服务。

## 使用边界

新增关卡与换画风请阅读源码中的 `docs/模块化关卡制作手册.md`。通用引擎模板默认保持草稿，不计入本版正式两关；生成模板不等于完成主题内容和美术审核。

本版有规则、动画、输入和离线自包含检查。详细结果与实际试玩范围以源码中的最新验收记录为准；本地 HTTP 试玩不等于已经在所有浏览器、实体手机或 file:// 模式逐一验收。

游戏用于应急科普练习，不能替代专业救援。公开商用前仍需自行完成内容安全、无障碍、真实设备与素材合规验收。
